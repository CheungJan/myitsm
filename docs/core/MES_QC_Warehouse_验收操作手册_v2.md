## 1. 验收前置条件

### 1.1 环境准备

- **数据库**：PostgreSQL 已有基础主数据（物料、仓库、BOM、标签）
- **后端**：Flask 服务已启动，质量门禁通过
- **前端**：Vue 前端已启动，可访问 MES/仓库/QC 模块
- **账号**：具备工单、仓库、质检操作权限的测试账号

### 1.2 数据准备

| 数据类型 | 准备内容 | 用途 |
|---------|---------|------|
| 物料 | 至少 3 类：配件（需标签）、耗材（无需标签）、成品（需标签） | IQC/FQC 验证 |
| BOM | 至少 1 个有效 BOM（含配件/耗材） | 生产领料验证 |
| 标签 | 每个物料类至少 10 个未激活标签 | 标签分配验证 |
| 仓库 | 至少 2 个仓库（新品库、成品库） | 出入库验证 |
| 供应商 | 至少 1 个有效供应商 | 采购入库验证 |

## 2. 模式A：独立质检（IQC）验收

### 2.1 业务场景

**目的**：验证采购来料质检流程，非生产触发。

**验收目标**：
- 采购入库 → 质检出库 → QC 录入 → QC 审核 → 质检入库
- 标签激活正确
- 不影响生产工单状态

### 2.2 操作步骤

#### 步骤1：采购入库

1. 进入 **入库单管理**
2. 点击 **新建**
3. 填写：
   - 入库类型：`IV=1` 采购入库
   - 仓库：选择新品库
   - 供应商：选择测试供应商
   - 明细：添加 2 行（配件、耗材）
     - 配件：物料编码、数量 10、物料状态 `DJ`（待检）
     - 耗材：物料编码、数量 5、物料状态 `DJ`
4. 点击 **保存**
5. 点击 **审核**
6. **验证点**：
   - 入库单状态变为 `已审核`
   - 库存增加（DJ 状态）

#### 步骤2：质检出库

1. 进入 **出库单管理**
2. 点击 **新建**
3. 填写：
   - 出库类型：`OV=5` 质检出库
   - 仓库：新品库
   - 来源单据：选择步骤1的采购入库单
4. 明细自动带出，核对数量
5. 点击 **保存**
6. 点击 **审核**
7. **验证点**：
   - 出库单状态变为 `已审核`
   - 库存扣减（DJ 状态）

#### 步骤3：质检录入

1. 进入 **质检管理 → 录入**
2. 来源类型选择：`质检出库`
3. 来源单据选择：步骤2的 OV=5 单号
4. 明细自动带出，填写：
   - 配件行：
     - 质检数量：10
     - EID：点击“+”生成标签或选择已有标签
     - 原厂序列号：填写测试值
     - 质检判定：`GA`（合格）
   - 耗材行：
     - 质检数量：5
     - EID列显示“无需标签”
     - 质检判定：`GA`（合格）
5. 点击 **提交质检**
6. **验证点**：
   - 质检单创建成功
   - 质检单号格式：`QC` + 日期 + 序号
   - 质检单状态：`待审核`

#### 步骤4：质检审核

1. 进入 **质检管理 → 结果列表**
2. 找到步骤3的质检单，点击 **审核**
3. **验证点**：
   - 质检单状态变为 `已审核`
   - 自动生成 `IV=11` 质检入库草稿
   - 配件 EID 状态：`qcflg='GA'`，标签激活（`useflg='0'`）
   - 耗材无 EID 状态变化

#### 步骤5：质检入库

1. 进入 **入库单管理**
2. 找到自动生成的 `IV=11` 草稿
3. 核对明细（仅合格物料）
4. 点击 **审核**
5. **验证点**：
   - 入库单状态变为 `已审核`
   - 库存增加（GA 状态）
   - 配件 EID：`sflg='1'`（在库），`whcd` 有值
   - 耗材库存增加

### 2.3 异常场景验收

| 场景 | 操作 | 预期结果 |
|------|------|---------|
| 质检判定 `BF`（报废） | 步骤3中配件行判定改为 `BF`，提交后审核 | 自动生成 `OV=7` 报废出库草稿，EID `sflg='2'` |
| 质检判定 `BH`（返修） | 步骤3中配件行判定改为 `BH`，提交后审核 | 自动生成 `OV=9` 返修出库草稿，EID `qcflg='BH'` |
| 质检判定 `TH`（退换） | 步骤3中耗材行判定改为 `TH`，提交后审核 | 自动生成 `OV=6` 退换出库草稿 |
| 未生成 OV=5 草稿 | 步骤2不审核，直接跳到步骤3 | 质检录入无法选择该采购入库单（系统过滤） |

## 3. 模式B：生产领料-EID（FQC）验收

### 3.1 业务场景

**目的**：验证 EID 模式生产工单领料、生产、FQC 流程。

**验收目标**：
- 工单下达自动生成 OV=8 草稿
- OV=8 审核推进工单到生产中
- 手动完工进入待最终检
- FQC 合格生成 IV=8 并完工工单

### 3.2 操作步骤

#### 步骤1：创建生产工单

1. 进入 **工单管理**
2. 点击 **新建**
3. 填写：
   - 工单类型：`PRODUCTION`（生产）
   - 产品编码：选择成品物料
   - 计划数量：10
   - 计划开始/完成日期：填写未来日期
4. 点击 **保存**
5. **验证点**：
   - 工单状态：`DRAFT`（草稿）

#### 步骤2：下达工单

1. 在工单列表找到步骤1的工单
2. 点击 **下达**
3. **验证点**：
   - 工单状态变为 `PICKING`（领料中）
   - 自动生成 `OV=8` 生产出库草稿
   - 草稿明细按 BOM 自动填充

#### 步骤3：生产出库审核

1. 进入 **出库单管理**
2. 找到自动生成的 `OV=8` 草稿
3. 核对明细（EID 模式）
4. 为配件行选择已有 EID（从 IQC 合格品中选择）
5. 点击 **审核**
6. **验证点**：
   - 出库单状态变为 `已审核`
   - 工单状态变为 `IN_PROGRESS`（生产中）
   - 工单 `actual_start` 自动填入当天日期
   - EID 状态：`sflg='7'`（生产中），`whcd=NULL`
   - `TMS04` 物料消耗记录写入

#### 步骤4：手动完工

1. 进入 **工单管理**
2. 找到步骤3的工单
3. 点击 **完工待检**
4. **验证点**：
   - 工单状态变为 `QC_PENDING`（待最终检）
   - 工单 `actual_end` 自动填入当天日期

#### 步骤5：FQC 质检录入

1. 进入 **质检管理 → 录入**
2. 来源类型选择：`生产工单`（系统按工单状态自动区分 FQC/IPQC）
3. 来源单据选择：步骤4的工单（`QC_PENDING` 状态）
5. 明细自动带出（成品行）
6. 填写：
   - 质检数量：10
   - EID：点击“+”生成新标签（成品标签格式：日期开头）
   - 原厂序列号：填写测试值
   - 质检判定：`GA`（合格）
7. 点击 **提交质检**
8. **验证点**：
   - 质检单创建成功
   - 质检单 `refbillid` 为工单号（`WO...`）

#### 步骤6：FQC 质检审核

1. 进入 **质检管理 → 结果列表**
2. 找到步骤5的质检单，点击 **审核**
3. **验证点**：
   - 质检单状态变为 `已审核`
   - 自动生成 `IV=8` 生产入库草稿
   - 工单状态变为 `COMPLETED`（已完工）
   - 成品 EID 状态：`qcflg='GA'`，标签激活，`sflg='1'`（在库）

#### 步骤7：生产入库

1. 进入 **入库单管理**
2. 找到自动生成的 `IV=8` 草稿
3. 核对明细（成品）
4. 点击 **审核**
5. **验证点**：
   - 入库单状态变为 `已审核`
   - 成品库存增加
   - 成品 EID：`whcd` 有值（成品库）

### 3.3 异常场景验收

| 场景 | 操作 | 预期结果 |
|------|------|---------|
| OV=8 草稿生成失败 | 工单下达时 BOM 不存在或物料无库存 | 工单状态卡在 `RELEASED`，可点击“取消”按钮取消工单 |
| 手动完工前未审核 OV=8 | 步骤3不审核，直接点击“完工待检” | 系统提示需先审核 OV=8 出库单 |
| FQC 判定 `BF`（报废） | 步骤5中成品行判定改为 `BF`，提交后审核 | 自动生成 `OV=7` 报废出库草稿，工单回退 `IN_PROGRESS` + 自动补料OV=8 |
| FQC 判定 `BH`（返修） | 步骤5中成品行判定改为 `BH`，提交后审核 | 自动生成 `OV=9` 返修出库草稿，工单回退 `IN_PROGRESS` + 自动补料OV=8 |
| 生产中补领 | 步骤3后，物料不足，新建 OV=8 关联同一工单，审核 | `TMS04` 累加去重，工单状态保持 `IN_PROGRESS` |
| 生产中 IPQC 判定 `BH`（返修） | 步骤3后，进入 IPQC 过程检，判定配件为 `BH` | 自动生成 `OV=9` 返修出库草稿，工单保持 `IN_PROGRESS` |
| 生产中 IPQC 判定 `BF`（报废） | 步骤3后，进入 IPQC 过程检，判定配件为 `BF` | 自动生成 `OV=7` 报废出库草稿，工单保持 `IN_PROGRESS` |
| FQC 判定 `TH`（退换） | 步骤5中成品行判定改为 `TH`，提交后审核 | 自动生成 `OV=6` 退换出库草稿，工单回退 `IN_PROGRESS` + 自动补料OV=8 |
| 生产中 IPQC 判定 `TH`（退换） | 步骤3后，进入 IPQC 过程检，判定配件为 `TH` | 自动生成 `OV=6` 退换出库草稿，工单保持 `IN_PROGRESS` |

## 4. 模式C：生产领料-批次（FQC）验收

### 4.1 业务场景

**目的**：验证批次模式生产工单领料、生产、FQC 流程（后贴标）。

**验收目标**：
- 批次模式出库（无 EID）
- FQC 合格后生成新 EID
- 工单状态流转正确

### 4.2 操作步骤

#### 步骤1-4：同模式B

- 创建工单、下达、出库审核、手动完工步骤与模式B相同
- **差异点**：
  - 步骤3 出库审核时，明细为批次模式（无 EID 列）
  - 步骤3 出库审核后，`TMS04` 写入批次明细

#### 步骤5：FQC 质检录入（批次模式）

1. 进入 **质检管理 → 录入**
2. 来源类型选择：`生产工单`（系统自动按工单状态进入对应质检模式）
3. 来源单据选择：`QC_PENDING` 状态工单
4. 明细自动带出（树形：成品+BOM配件）
6. 填写：
   - 质检数量：10
   - EID：点击“+”生成新标签（成品标签）
   - 质检判定：`GA`（合格）
7. 点击 **提交质检**
8. **验证点**：
   - 质检单创建成功
   - 质检单明细为批次模式（`TQC11_RESULTDT`）

#### 步骤6-7：同模式B

- FQC 审核、生产入库步骤与模式B相同
- **差异点**：
  - 步骤6 审核后，自动生成 `IV=8` 草稿明细为批次模式
  - 步骤7 入库审核后，成品 EID 为新生成

### 4.3 异常场景验收

| 场景 | 操作 | 预期结果 |
|------|------|---------|
| 批次物料无标签 | 步骤5中点击“+”生成标签失败（标签池耗尽） | 系统提示标签不足，需先生成标签 |
| 批次日期丢失 | 步骤3出库审核时批次日期未带入 | 后续 FQC 入库时批次日期为空（需人工补填） |
| 批次模式 IPQC 判定 `BH`（返修） | 步骤3后，进入 IPQC 过程检，判定批次物料为 `BH` | 自动生成 `OV=9` 返修出库草稿，工单保持 `IN_PROGRESS` |
| 批次模式 IPQC 判定 `BF`（报废） | 步骤3后，进入 IPQC 过程检，判定批次物料为 `BF` | 自动生成 `OV=7` 报废出库草稿，工单保持 `IN_PROGRESS` |
| 批次模式 IPQC 判定 `TH`（退换） | 步骤3后，进入 IPQC 过程检，判定批次物料为 `TH` | 自动生成 `OV=6` 退换出库草稿，工单保持 `IN_PROGRESS` |

## 5. 模式D：旧机翻新验收

### 5.1 业务场景

**目的**：验证翻新工单流程，新旧 EID 溯源。

**验收目标**：
- OV=10 翻新出库
- 标签激活新 EID
- IV=6 翻新入库，新旧 EID 溯源

### 5.2 操作步骤

#### 步骤1：创建翻新工单

1. 进入 **工单管理**
2. 点击 **新建**
3. 填写：
   - 工单类型：`RENOVATION`（翻新）
   - 产品编码：选择成品物料
   - 计划数量：5
4. 点击 **保存**
5. **验证点**：
   - 工单状态：`DRAFT`

#### 步骤2：翻新出库

1. 进入 **出库单管理**
2. 点击 **新建**
3. 填写：
   - 出库类型：`OV=10` 翻新出库
   - 仓库：选择旧机库
   - 来源单据：关联步骤1的工单
4. 明细：选择旧 EID（`sflg='8'` 或 `qcflg='BF'`）
5. 点击 **保存** → **审核**
6. **验证点**：
   - 出库单状态变为 `已审核`
   - 旧 EID 状态：`sflg='7'`（翻新中）
   - `TMS04` 记录写入

#### 步骤3：标签激活新 EID

1. 进入 **标签管理**
2. 为成品物料生成新标签（数量 5）
3. 激活标签
4. **验证点**：
   - 新标签状态：`useflg='0'`
   - `TMM43_EID` 记录生成

#### 步骤4：翻新入库

1. 进入 **入库单管理**
2. 点击 **新建**
3. 填写：
   - 入库类型：`IV=6` 翻新入库
   - 仓库：成品库
4. 明细：
   - 旧 EID 行：`sflg='8'`，`qcflg='BF'`
   - 新 EID 行：`ref_eid` 填写旧 EID
5. 点击 **保存** → **审核**
6. **验证点**：
   - 入库单状态变为 `已审核`
   - 新 EID 状态：`sflg='1'`（在库）
   - 新旧 EID 溯源关系建立（`ref_eid`）

#### 步骤5：手动完工

1. 进入 **工单管理**
2. 找到步骤1的翻新工单
3. 点击 **完工待检**
4. **验证点**：
   - 工单状态变为 `QC_PENDING`（待最终检）

#### 步骤6：FQC 质检录入

1. 进入 **质检管理 → 录入**
2. 来源类型选择：`生产工单`（系统自动按工单状态进入对应质检模式）
3. 来源单据选择：步骤5的工单（`QC_PENDING` 状态）
5. 明细自动带出（成品行）
6. 填写：
   - 质检数量：5
   - EID：选择步骤4生成的新 EID
   - 质检判定：`GA`（合格）
7. 点击 **提交质检**
8. **验证点**：
   - 质检单创建成功
   - 质检单 `refbillid` 为工单号（`WO...`）

#### 步骤7：FQC 质检审核

1. 进入 **质检管理 → 结果列表**
2. 找到步骤6的质检单，点击 **审核**
3. **验证点**：
   - 质检单状态变为 `已审核`
   - 自动生成 `IV=8` 生产入库草稿
   - 工单状态变为 `COMPLETED`（已完工）
   - 成品 EID 状态：`qcflg='GA'`，`sflg='1'`（在库）

#### 步骤8：生产入库

1. 进入 **入库单管理**
2. 找到自动生成的 `IV=8` 草稿
3. 核对明细（成品）
4. 点击 **审核**
5. **验证点**：
   - 入库单状态变为 `已审核`
   - 成品库存增加
   - 成品 EID：`whcd` 有值（成品库）

### 5.3 异常场景验收

| 场景 | 操作 | 预期结果 |
|------|------|---------|
| 翻新中途换件有缺陷(IPQC) | OV=10 审核后，工单 `IN_PROGRESS`，进入 IPQC 过程检，判定换件为 `BH` | 自动生成 `OV=9` 返修出库，工单保持 `IN_PROGRESS` |
| 翻新后 FQC 不合格 | `QC_PENDING` 后 FQC 判定 `BF` | 生成 `OV=7` 报废出库，工单回退 `IN_PROGRESS` + 自动补料OV=8 |
| 翻新需补领物料 | 拆解后发现缺件，新建 `OV=8` 关联同工单 | `TMS04` 累加，EID 不重复扣减 |
| 旧 EID 已报废无法翻新 | 选择 `sflg='2'` 的旧 EID 做 `OV=10` | 系统拒绝出库或提示 EID 状态异常 |

## 6. 三种 QC 类型验收

### 6.1 IQC（来料检）验收

**验收点**：
- **触发条件**：`OV=5` 质检出库后
- **refbillid**：`OT...`（质检出库单号）
- **状态影响**：不影响工单
- **仓库动作**：`GA/GB/GC` → `IV=11` 质检入库

**验收步骤**：见 **模式A** 验收

### 6.2 IPQC（过程检）验收

**适用模式**：模式B（生产领料-EID）、模式C（生产领料-批次）、模式D（旧机翻新）

**业务场景**：生产过程中发现配件损坏、物料质量问题，需要返修/报废/退换处理。

**验收点**：
- **触发条件**：工单状态 `IN_PROGRESS` 生产中
- **refbillid**：`WO...`（工单号）
- **状态影响**：不改变工单主状态
- **仓库动作**：`GA/GB/GC` 不入库，只标记 EID 状态；`BH/BF/TH` 生成 `OV=6/7/9` 出库单

**验收步骤**：
1. 工单进入 `IN_PROGRESS` 状态（模式B步骤3后）
2. 进入 **质检管理 → 录入**
3. 来源类型选择：`生产工单`（系统自动按工单状态进入对应质检模式）
4. 来源单据选择：`IN_PROGRESS` 状态工单
6. 明细自动带出（BOM 子件物料）
7. 填写：
   - 选择异常物料行
   - 质检数量：填写异常数量
   - 质检判定：`BH`（返修）/`BF`（报废）/`TH`（退换）
8. 点击 **提交质检**
9. **验证点**：
   - 质检单创建成功
   - 质检单 `refbillid` 为工单号（`WO...`）

**异常场景验收**：
| 场景 | 操作 | 预期结果 |
|------|------|---------|
| IPQC 判定 `BH`（返修） | 步骤7中质检判定改为 `BH`，提交后审核 | 自动生成 `OV=9` 返修出库草稿，工单状态保持 `IN_PROGRESS` |
| IPQC 判定 `BF`（报废） | 步骤7中质检判定改为 `BF`，提交后审核 | 自动生成 `OV=7` 报废出库草稿，工单状态保持 `IN_PROGRESS` |
| IPQC 判定 `TH`（退换） | 步骤7中质检判定改为 `TH`，提交后审核 | 自动生成 `OV=6` 退换出库草稿，工单状态保持 `IN_PROGRESS` |
| IPQC 判定 `BH`（返修） | 步骤7中质检判定改为 `BH`，提交后审核 | 自动生成 `OV=9` 返修出库草稿 + 自动补料 OV=8（关联同工单，TMS04累加），工单保持 `IN_PROGRESS` |
| IPQC 判定 `BF`（报废） | 步骤7中质检判定改为 `BF`，提交后审核 | 自动生成 `OV=7` 报废出库草稿 + 自动补料 OV=8，工单保持 `IN_PROGRESS` |
| IPQC 判定 `TH`（退换） | 步骤7中质检判定改为 `TH`，提交后审核 | 自动生成 `OV=6` 退换出库草稿 + 自动补料 OV=8，工单保持 `IN_PROGRESS` |
| IPQC 判定 `GA`（合格） | 步骤7中质检判定改为 `GA`，提交后审核 | 不生成入库单，只标记 EID 状态，工单状态保持 `IN_PROGRESS` |

### 6.3 FQC（最终检）验收

**适用模式**：模式B（生产领料-EID）、模式C（生产领料-批次）、模式D（旧机翻新）

**验收点**：
- **触发条件**：工单状态 `QC_PENDING` 待最终检
- **refbillid**：`WO...`（工单号）
- **状态影响**：`GA/GB/GC` 触发 `QC_PENDING → COMPLETED`
- **仓库动作**：`GA/GB/GC` → `IV=8` 生产入库

**验收步骤**：见 **模式B/C/D** 验收步骤5-7（模式B/C为步骤5-7，模式D为步骤6-8）

#### 6.3.1 FQC 不良处理验收

**适用模式**：模式B（生产领料-EID）、模式C（生产领料-批次）、模式D（旧机翻新）

**业务场景**：FQC 判定成品为不良品（BH/BF/TH）时，不良品不入生产库，而是走暂存→异常出库流程 + 自动补料。

**验收步骤**：
1. 工单进入 `QC_PENDING` 状态（同FQC合格步骤1-4）
2. 进入 **质检管理 → 录入**，来源类型选择 `生产工单`（系统自动按工单状态区分），来源单据选择 `QC_PENDING` 工单
4. 质检判定填写：`BH`（返修）/ `BF`（报废）/ `TH`（退换）
5. 点击 **提交质检** → 进入 **结果列表** → 点击 **审核**
6. **验证点**：
   - 自动生成 `IV=11` 暂存入库草稿（L1/BF、LS/BH-TH）
   - 自动生成 `OV=8` 补料出库草稿（关联同工单）
   - 工单从 `QC_PENDING` 回退到 `IN_PROGRESS`
   - EID 状态：`qcflg='BH/BF/TH'`，`sflg='3'`（待检）

## 7. 状态机验收

### 7.1 工单状态流转验收

| 当前状态 | 可流转状态 | 触发方式 | 验证点 |
|---------|-----------|---------|--------|
| `DRAFT` | `RELEASED`、`CANCELLED` | 前端按钮 | 下达后自动生成 OV=8 草稿并进入 `PICKING` |
| `RELEASED` | `PICKING`、`CANCELLED` | 系统自动/前端按钮 | 若 OV=8 生成失败，可手动取消 |
| `PICKING` | `IN_PROGRESS`、`CANCELLED` | OV=8 审核/前端按钮 | OV=8 审核后自动进入 `IN_PROGRESS` |

| `COMPLETED` | 无 | 终态 | 不可再流转 |
| `CANCELLED` | 无 | 终态 | 不可再流转 |

## 10. 常见问题排查

### 10.1 工单下达后卡在 RELEASED

**原因**：OV=8 草稿生成失败（BOM 不存在、物料无库存）

**排查**：
1. 检查工单产品是否有有效 BOM
2. 检查 BOM 物料是否有库存
3. 查看后端日志是否有错误

**解决**：
- 补充 BOM 或库存
- 或点击“取消”按钮取消工单

### 10.2 FQC 审核后工单未完工

**原因**：质检单 `refbillid` 不是工单号，或工单状态不是 `QC_PENDING`

**排查**：
1. 检查质检单 `refbillid` 是否为 `WO...`
2. 检查工单状态是否为 `QC_PENDING`
3. 查看后端日志是否有错误

**解决**：
- 确保质检录入时选择“生产工单”来源
- 确保工单已手动完工进入 `QC_PENDING`

### 10.3 标签生成失败

**原因**：标签池耗尽或标签生成服务异常

**排查**：
1. 检查标签表是否有未激活标签
2. 查看后端日志是否有错误

**解决**：
- 手动生成标签
- 或联系管理员补充标签池

## 附录D：标签ID跨表关联运维

标签 ID（如 BS42002660001）在以下四个表中透传，修改时需同步更新：

```
TMM40_LABEL          标签主表（生成、激活状态）
    ↓ QC C1 审核激活
TMM43_EID             设备记录（sflg/qcflg/whcd）
    ↓ QC 结果录入
TQC11_RESULTEID       质检明细-按EID（qcqty/qcstatus）
    ↓ QC 审核 → IV=11
TWH14_CHECKINDT       入库明细（eid 字段）
```

**标签 ID 修复 SQL（四表同步）**：
```sql
UPDATE tmm40_label      SET labelid = '<新标签号>' WHERE labelid = '<旧标签号>';
UPDATE tmm43_eid        SET eid     = '<新标签号>' WHERE eid     = '<旧标签号>';
UPDATE tqc11_resulteid  SET eid     = '<新标签号>' WHERE eid     = '<旧标签号>';
UPDATE twh14_checkindt  SET eid     = '<新标签号>' WHERE eid     = '<旧标签号>';
```

**生成规则（配件 typflg='0'）**：
```
classcd(补零至6位) + YY + 月份后缀(1-9→月份本身,10→A,11→B,12→C) + 4位序号
例：BS42 → BS4200 + 26 + 6 + 0001 → BS42002660001
```

**生成规则（成品 typflg='1'）**：
```
YYYYMMDD + sign(标识) + 4位序号
例：20260609 + L + 0001 → 20260609L0001
```
