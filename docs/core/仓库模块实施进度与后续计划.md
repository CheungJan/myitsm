## 三、前端页面设计

### 统一入口设计

```
仓库管理
├── 入库单管理（统一） ← 需加新建表单 + invtyp 下拉 + 条件字段
│   ├── 列表：单号/类型/仓库/来源单号/数量/审核状态/操作
│   └── 新建弹窗：invtyp 下拉 → 动态显示关联字段
│        ├── invtyp=1: 来源订单号(自动/手动)、供应商
│        ├── invtyp=4: 来源调拨出库单、目标仓库
│        └── invtyp=8: 手动填物料、数量、仓库
│
├── 出库单管理（已完善）
│   ├── 列表：单号/关联单据/仓库/类型/日期/审核/操作 ✅
│   ├── 审核弹窗 ✅
│   └── 新建弹窗：🖐 待加
│
├── 库存查询 ✅ (已修复 itemqty + 仓库/物料名称)
├── 货位变更（已有）
├── 资产盘点（已有，历史数据）
└── 盘盈盘亏 ← 需加新建/审核按钮
```
