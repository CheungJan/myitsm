## 六、行业标准对照（WMS 五层模型）

参照 SAP WM / Oracle WMS / 金蝶用友仓储：

| 层 | 功能 | 我们状态 |
|----|------|---------|
| 基础台账 | 仓库/物料/库位/即时库存/流水 | ✅ TWH11/12 已就绪 |
| 入库管理 | 8 种 invtyp 统一入口 | ✅ |
| 出库管理 | 8 种 invtyp 统一入口 | ✅ |
| 库存控制 | 安全库存/序列号/库龄/成本 | ⚠️ 有 EID+安全库存，缺库龄 |
| 盘点管理 | 盘盈盘亏+资产盘点+循环盘点 | ✅ 前两项完成 |

**我们特有的能力**（普通 WMS 没有）：

| 特点 | 说明 |
|------|------|
| EID 设备级追踪 | 出库明细精确到序列号 |
| ITSM 维护闭环 | 仓库与工单双向联动——领料/返还 |
| 租赁资产管理 | 出库≠销售，设备会回来 |
| 质检中间态 | 采购入库→质检→合格入库，多一个环节 |
