## 三、数据迁移记录

### 3.1 迁移映射

| 机型 | BOM 前缀 | 押金 | 售价 | 迁移条数 |
|------|---------|------|------|---------|
| 单屏/双屏/4Q | 4Q4 | 3000 | 3000 | 21 |
| 7Q | 7Q | 3000 | 3000 | 14 |
| 海晟(HS0101) | HS | 0 | 0 | 0(押金为 0,无需迁移) |
| **合计** | | | | **35** |

> **海晟说明**: `DepositPosModel` 中海晟记录 `rent_money=0.00`、`sale_money=0.00`,
> 对应 BOM `HS0101`(useflg=1,在产)。因押金/售价均为 0,迁移脚本跳过,
> `tip01_price` 无 HS 开头 busityp=40 记录。如后续业务确认海晟机型需押金,
> 直接在价格管理页为 `HS0101` 新增 `busityp=40` 记录即可。

### 3.2 迁移脚本

`scripts/migrate_deposit_posmodel_to_price.py`(一次性,已执行)。

## 四、API 接口验收

### 4.1 在产机型接口

**路径**: `GET /api/v1/items/pos-models`
**认证**: Bearer Token
**返回结构**:

```json
{
  "code": 200,
  "data": [
    {
      "item_cd": "4Q4001",
      "item_nm": "TFP4000 4001(CPA33T2NNUYNN)",
      "rent_money": 3000.0,
      "sale_money": 14640.0
    }
  ]
}
```

**SQL 等价**:

```sql
SELECT i.item_cd, i.item_nm,
       pr.itemprice AS rent_money,
       ps.itemprice AS sale_money
FROM tmm12_items i
JOIN tmm41_bom b ON b.bomcd = i.item_cd
LEFT JOIN tip01_price pr ON pr.itemcd = i.item_cd AND pr.busityp = '40'
LEFT JOIN tip01_price ps ON ps.itemcd = i.item_cd AND ps.busityp = '10'
WHERE i.typflg = '1' AND i.useflg = '1' AND b.useflg = '1'
ORDER BY i.item_cd;
```

## 六、PB 语义对齐说明

PB 源码中 `tmm41_bom.useflg='1'` 同时承担两个职责:
1. **配方有效**: BOM 数据本身可用
2. **机型在产可选**: 销售计划可选该机型

参考 PB 源码:
- `w_wh_scout_pop.srw:638`
- `w_r_sl_audit_direct.srw:246`
- `w_r_mm_label_zjpj.srw:63`

**决策**: 不新增 `is_production` 字段,复用 `Bom.useflg` 作为在产机型筛选条件,避免数据冗余。

### 8.3 数据一致性校验

```sql
-- 押金一致性: DepositPosModel 与 tip01_price 对比
SELECT d.model_cd, d.rent_money AS old_rent,
       p.itemprice AS new_rent
FROM tmm61_deposit_posmodel d
JOIN tmm41_bom b ON b.bomcd LIKE
  CASE d.model_cd
    WHEN '单屏' THEN '4Q4%'
    WHEN '双屏' THEN '4Q4%'
    WHEN '4Q' THEN '4Q4%'
    WHEN '7Q' THEN '7Q%'
    WHEN '海晟' THEN 'HS%'
  END
LEFT JOIN tip01_price p ON p.itemcd = b.bomcd AND p.busityp = '40'
WHERE d.rent_money > 0
LIMIT 5;
```
