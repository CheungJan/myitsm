# 采购结算与退货功能操作手册

## 1. 文档目的

本文档面向采购结算单与采购退货单的使用人员，说明页面布局、操作流程、字段含义与注意事项，帮助用户正确使用结算与退货功能。

## 2. 功能概述

### 2.1 采购结算单

采购结算单用于对已审核采购订单进行结算，记录供应商发票信息、结算金额、付款方式等，支持按付款方式（COD/PIA/DEP/MON/INS）区分可结算数量口径。

### 2.2 采购退货单

采购退货单用于对已入库采购订单进行退货，记录退货原因、退货数量、退货单价、设备信息等，退货数量不能超过已入库数量。

## 4. 采购结算单操作流程

### 4.1 新建结算单

#### 步骤 1：打开新建弹窗

点击右上角 **新建结算单** 按钮。

#### 步骤 2：选择供应商

在弹窗中选择供应商。

系统自动加载该供应商**所有已审核采购订单**的可结算商品行，无需手动选择订单。接口调用：

```text
/api/v1/procurement/orders/<订单号>/settleable-items
```

#### 步骤 3：查看可结算明细

明细表显示：

| 字段 | 说明 |
|---|---|
| 来源订单 | 采购订单号 |
| 物料编码 | 物料编码 |
| 订单数量 | 订购数量 |
| 已收货 | 已入库数量 |
| 已结算 | 已结算数量 |
| 可结算（COD） | 已入库 - 已结算 |
| 可结算（PIA） | 订购数量 - 已结算 |
| 本次结算数量 | 用户输入 |
| 结算单价 | 默认来自订单单价，可修改 |

#### 步骤 4：填写结算信息

在明细表中勾选要结算的行，填写：

- **本次结算数量**：不能超过可结算余量
- **结算单价**：默认订单单价，可修改

主表填写：

- **付款方式**：选择 COD/PIA/DEP/MON/INS
- **发票号**：可选
- **发票日期**：可选
- **结算日期**：可选
- **仓库**：可选
- **备注**：可选

#### 步骤 5：提交创建

点击 **确定** 创建结算单。

创建成功后列表新增一条记录，审批状态为 **未审核**。

### 4.2 编辑结算单

#### 适用条件

- 仅未审核（`auditflg = 0`）的结算单可编辑
- 已审核、已作废单据不可编辑

#### 操作步骤

1. 点击列表行的 **编辑** 按钮
2. 弹窗加载当前结算单信息
3. 可修改主表字段（单号、明细、制单人、审核字段不可修改）
4. 可全量替换明细（先清空原明细，再写入新明细）
5. 点击 **确定** 保存

#### 注意事项

- 编辑时结算数量校验会排除当前结算单自身已结算数量
- 编辑后审批状态仍为未审核

### 4.3 送审结算单

#### 适用条件

- 仅未审核（`auditflg = 0`）的结算单可送审

#### 操作步骤

1. 点击列表行的 **送审** 按钮
2. 系统调用审核接口，将 `auditflg` 设置为 `1`（送审/待审核）
3. 送审成功后，操作列显示 **审核** 按钮

### 4.4 审核结算单

#### 适用条件

- 仅送审状态（`auditflg = 1`）的结算单可审核

#### 操作步骤

1. 点击列表行的 **审核** 按钮
2. 弹出审核对话框，显示结算单基本信息与明细
3. 点击 **通过** 或 **驳回**
4. 审核通过后 `auditflg` 设置为 `2`（已审核）
5. 审核驳回后 `auditflg` 仍为 `1`，可重新送审

#### 注意事项

- 已审核通过的结算单不能作废
- 已审核通过的结算单不能编辑

### 4.5 作废结算单

#### 适用条件

- 未审核（`auditflg = 0`）或送审（`auditflg = 1`）的结算单可作废
- 已审核通过（`auditflg = 2`）的结算单不能作废

#### 操作步骤

1. 点击列表行的 **作废** 按钮
2. 确认作废操作
3. 系统同时设置 `useflg = "9"` 和 `auditflg = "9"`
4. 作废后单据不可编辑、不可审核

### 4.6 查看结算单详情

#### 操作步骤

1. 点击列表行任意位置
2. 弹出详情对话框
3. 显示主表信息与结算明细
4. 显示发票状态（已开/未开）

#### 详情包含字段

- 结算单号
- 供应商
- 付款方式
- 结算金额
- 发票号
- 发票日期
- 审批人
- 审批日期
- 仓库
- 发票状态（已开/未开）
- 备注
- 结算明细（来源订单、物料、订单数量、已收货、已结算、本次结算数量、结算单价、结算金额）

## 6. 结算数量规则

### 6.1 付款方式与可结算数量

| 付款方式 | 可结算数量口径 | 说明 |
|---|---|---|
| COD（货到付款） | 已入库数量 - 已结算数量 | 按实际入库结算 |
| MON（月结） | 已入库数量 - 已结算数量 | 按实际入库结算 |
| PIA（款到发货） | 订购数量 - 已结算数量 | 按订购数量结算 |
| DEP（预付+尾款） | 订购数量 - 已结算数量 | 按订购数量结算 |
| INS（分期付款） | 订购数量 - 已结算数量 | 按订购数量结算 |

### 6.2 结算数量校验

- 本次结算数量不能超过可结算余量
- 编辑结算单时，已结算数量会排除当前结算单自身
- 超量结算会提示错误：

```text
订单 <订单号> 行 <行号> 结算数量(<数量>)超过可结算余量(<余量>)
```

## 7. 退货数量规则

### 7.1 可退货数量

```text
可退货数量 = 已入库数量 - 已退货数量
```

### 7.2 退货数量校验

- 来源订单行必须存在
- 来源订单行必须有入库数量
- 本次退货数量必须大于 0
- 本次退货数量不能超过可退货余量
- 超量退货会提示错误：

```text
行 <行号> 退货数量(<数量>)超过可退余量(<余量>)
```

## 8. 常见问题

### Q1：新建结算单时没有可结算明细？

**可能原因**：

- 选中的供应商没有已审核采购订单
- 订单没有明细
- 订单没有入库数量（COD/MON 场景）
- 订单已全部结算（可结算余量为 0）

**解决方法**：

- 先到采购订单页面确认是否有已审核订单
- 确认订单是否有入库数量
- 确认订单是否已全部结算

### Q2：新建退货单时没有可退货明细？

**可能原因**：

- 选中的订单未审核
- 订单没有入库数量
- 订单已全部退货（可退货余量为 0）

**解决方法**：

- 先到采购订单页面确认订单状态
- 确认订单是否有入库数量
- 确认订单是否已全部退货

### Q3：结算单编辑时提示超过可结算余量？

**原因**：

编辑时系统会排除当前结算单自身已结算数量，但如果之前已结算数量较大，编辑后新数量仍可能超过余量。

**解决方法**：

- 减少本次结算数量
- 或选择其他订单行进行结算

### Q4：已审核结算单能否作废？

**不能**。

已审核通过（`auditflg = 2`）的结算单不能作废。如需作废，需先联系系统管理员处理。

### Q5：已审核退货单能否作废？

**不能**。

已审核通过（`auditflg = 2`）的退货单不能作废。如需作废，需先联系系统管理员处理。

### Q6：作废单据能否恢复？

**不能**。

作废单据同时设置 `useflg = "9"` 和 `auditflg = "9"`，无法恢复。如需恢复，需联系系统管理员处理。

### Q7：发票状态在哪里查看？

发票状态（`invoiceflg`）不在列表列中，仅在点击列表行后的详情弹窗中显示（已开/未开）。
