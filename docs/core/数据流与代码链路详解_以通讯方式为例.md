## 二、为什么数据库不直接存中文？

| 设计原则       | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| **数据一致性** | 字典统一维护，改一处生效全局。如果每个客户都存 `'实时+电信光纤'`，哪天改成 `'实时+电信FTTH光纤'` 就要更新所有客户记录 |
| **防止脏数据** | 编码是有限集合（`0311` 只能是字典里的值），中文容易出现 `'光纤'` / `'光迁'` / `'实时电信光纤'` 等拼写差异 |
| **报表友好**   | 按编码排序/分组有稳定语义，按中文则依赖字典翻译              |
| **存储效率**   | `'0311'` (4字节) vs `'实时+电信光纤'` (21字节 UTF-8)         |

类似的编码→中文翻译模式在系统中大量使用：客户分类(`classcd`)、支付方式(`zf_type`)、业务类型(`busityp`)等，**原理完全一致**。

### 第 3 层：后端路由接收请求

### 第 4 层：Service 查询客户并翻译编码

**文件**：`app/services/system_service.py`

```python
# 第 709-712 行
def get_customer(self, cust_cd: str) -> dict[str, Any] | None:
    r = self._repo.get_customer(cust_cd)           # ① 查 ORM 对象
    return self._resolve_customer_refs(r.to_dict()) if r else None  # ② 翻译编码
```

这里做了两件事：

**① `self._repo.get_customer(cust_cd)`** → 查数据库，返回 ORM 对象

**② `self._resolve_customer_refs(r.to_dict())`** → 把编码翻译成中文

### 第 5 层：Repository 执行 SQL 查询

**文件**：`app/repositories/system_repository.py`

```python
# 第 997-998 行
@staticmethod
def get_customer(cust_cd: str) -> Customer | None:
    return db.session.get(Customer, cust_cd)
```

**实际执行的 SQL**（由 SQLAlchemy 生成）：

```sql
SELECT *
FROM tmm22_customers
WHERE cust_cd = '00001225';
```

**返回的 ORM 对象**：`Customer` 实例，`customer.comm_mode = '0311'`。

> `db.session.get(Model, pk)` 是 SQLAlchemy 按主键查询的快捷方法，等价于 `db.session.query(Customer).filter(Customer.cust_cd == '00001225').first()`。

### 第 6 层：to_dict() 序列化

**文件**：`app/models/base.py`

```python
# 第 31-45 行
def to_dict(self) -> dict[str, Any]:
    result: dict[str, Any] = {}
    for column in self.__table__.columns:      # 遍历表的所有列
        if column.name in self._hidden_fields:
            continue
        value = getattr(self, column.name)      # 读取列值
        if isinstance(value, (datetime, date)):
            value = value.isoformat()             # 日期 → "2026-07-13T..."
        elif isinstance(value, Decimal):
            value = float(value)                  # Decimal → float
        elif isinstance(value, bytes):
            value = None                          # 二进制不返回
        result[column.name] = value
    return result
```

**执行过程**：遍历 `tmm22_customers` 表的所有列，生成 Python dict：

```python

    "phoneno":    "...",
```

### 第 7 层：`_resolve_customer_refs` 字典翻译

**文件**：`app/services/system_service.py`

#### 7a. 翻译逻辑

```python
# 第 580-581 行
# 通讯方式（tmm31_syscodes code_typ='CM'）
cust["comm_mode_nm"] = cache["cm"].get(cust.get("comm_mode", ""), "")
```

这一行的含义：

| 表达式 | 值 | 说明 |
|--------|-----|------|
| `cust.get("comm_mode", "")` | `"0311"` | 从客户 dict 取编码 |
| `cache["cm"]` | `{"01":"电话拨号", ..., "0311":"实时+电信光纤"}` | 字典缓存 |
| `.get("0311", "")` | `"实时+电信光纤"` | 查字典翻译 |
| `cust["comm_mode_nm"] = ...` | 追加字段 | 把中文名追加到 dict |

**关键设计**：`comm_mode_nm` **不是数据库字段**，是 Service 层追加的**派生字段**。

#### 7b. 字典缓存初始化

```python
# 第 617-646 行
def _build_ref_cache(self) -> dict[str, dict[str, str]]:
    cache: dict[str, dict[str, str]] = {}
    
    # ... 其他字典 ...
    
    # 通讯方式 CM
    cache["cm"] = {}
    for c in repo.get_syscodes("CM"):
        cache["cm"][c.code_cd] = c.code_nm or ""
    
    return cache
```

**执行的 SQL**：

```sql
SELECT code_cd, code_nm
FROM tmm31_syscodes
WHERE code_typ = 'CM'
  AND useflg = '1'
ORDER BY sort_no;
```

**构建的缓存**：

```python
cache["cm"] = {
    "01":   "电话拨号",
    "0101": "16300",
    "02":   "3G路由器",
    "0201": "电信3G卡",
    "0311": "实时+电信光纤",
    ...
}
```

#### 7c. 为什么一次性加载？

`_build_ref_cache()` 在 `SystemService.__init__` 中调用一次，之后所有请求共享：

```python
# 伪代码示意
class SystemService:
    def __init__(self):
        self._ref_cache = self._build_ref_cache()  # 只执行一次
    
    def get_customer(self, cust_cd):
        return self._resolve_customer_refs(...)      # 每次请求用缓存
```

**如果每查一个客户就查一次字典**（N+1 问题）：
- 查 100 个客户 = 1 次客户查询 + 100 次字典查询 = 101 次 SQL
- 其中 100 次字典查询完全重复

**一次性加载后**：
- 查 100 个客户 = 1 次客户查询 + 0 次字典查询 = 1 次 SQL
- 字典翻译是 Python 字典的 `O(1)` 查找

## 五、同类编码翻译一览

系统中所有"存编码、翻译显示"的字段都遵循同一个模式：

| 字段 | 编码列 | 中文名列 | 字典 code_typ | 翻译代码位置 |
|------|--------|---------|-------------|------------|
| 通讯方式 | `comm_mode` | `comm_mode_nm` | `CM` | `system_service.py:581` |
| 支付方式 | `zf_type` | `zf_type_nm` | `ZF` | `system_service.py:579` |
| 客户类别 | `class_cd` | `class_nm` | 查 `tmm21_custclass` | `system_service.py:573` |
| 业务类型 | `busi_typ` | `busi_typ_nm` | `BT` | `system_service.py:572` |
| 品牌 | `ppt_code` | `ppt_code_nm` | `YB` | `system_service.py:575` |
| 云类别 | `yun_type` | `yun_type_nm` | `PY` | `system_service.py:577` |
| 环线位置 | `location` | `location_nm` | `WZ` | `system_service.py:586` |
| 计划类型 | `plantyp` | — | `PL` | 前端 `useDict('PL')` |

**模式识别**：凡是字段名以 `_nm` 结尾或模型注释中有"编码/字典"字样的，都是编码翻译字段。新增此类字段时，参照 `comm_mode` → `comm_mode_nm` 的模式即可。
