# 仓库模块操作手册

## 一、功能概览

仓库模块已完成 P0/P1/P1.5/P2 全部独立功能，包括：

- **入库管理**：8 种入库类型统一入口，支持采购入库、销售退货、服务返还、调拨等
- **出库管理**：8 种出库类型统一入口，支持销售出库、服务领用、调拨、退货出库等
- **库存查询**：实时库存查询、库存流水查询
- **盘点管理**：资产盘点、盘盈盘亏
- **报表分析**：收发存汇总、库存日报、库龄分析

---

## 二、入库管理

### 2.1 采购入库（invtyp=1）

**业务场景**：采购订单审核后，供应商发货到仓库，仓库操作员办理入库。

**操作步骤**：

1. 打开"入库单管理"页面
2. 点击"新建"按钮
3. 选择入库类型：**采购入库**
4. 填写关联单据号：输入采购订单号（如 PR001559），供应商可选填
5. 选择入库仓库：选择实际入库仓库（如 04 生产配件库）
6. 手动填写入库明细：物料编码（可搜索）、数量、关联行号
6. 填写入库日期：默认当天，可修改
7. 完善入库明细：
   - 修改实际入库数量（可少于订购数量）
   - 填写批次号（可选）
   - 关联行号自动带出
8. 点击"保存"生成草稿单
9. 点击"审核"：
   - 系统自动更新 TPC13.inqty（入库数量累加）
   - 系统自动更新 TWH11/12 库存
   - 系统自动更新 TPC20 linkstatus（ordered → partial_in/completed）
   - 系统写入 TWH12 库存流水

**注意事项**：
- 采购订单审核后会自动生成入库草稿，仓库操作员只需选择仓库后审核
- 入库数量不能超过订购数量
- 审核通过后不可修改

---

### 2.2 销售退货入库（invtyp=2）

**业务场景**：客户退货的设备/配件重新入库。

**操作步骤**：

1. 打开"入库单管理"页面
2. 点击"新建"按钮
3. 选择入库类型：**销售退货入库**
4. 选择来源单据号：填写销售退货单号
5. 选择入库仓库
6. 填写入库明细：物料、数量
7. 保存并审核

---

### 2.3 服务返还入库（invtyp=3）

**业务场景**：ITSM 维护工单完成后，工程师将更换下来的旧配件/设备返还仓库。

**操作步骤**：

1. 打开"入库单管理"页面
2. 点击"新建"按钮
3. 选择入库类型：**服务返还入库**
4. 选择来源单据号：填写 ITSM 维护工单号
5. 选择入库仓库
6. 填写入库明细
7. 保存并审核

**后续处理**：
- 可翻新 → 翻新入库（invtyp=6）
- 可回收 → 回收入库（invtyp=7）
- 报废 → 报废出库（invtyp=7）

---

### 2.4 调拨入库（invtyp=4）

**业务场景**：仓库之间调拨，目标仓库接收货物。

**操作步骤**：

1. 打开"入库单管理"页面
2. 点击"新建"按钮
3. 选择入库类型：**调拨入库**
4. 选择来源单据号：填写调拨出库单号
5. 选择入库仓库（目标仓库）
6. 填写入库明细
7. 保存并审核

---

### 2.5 其他入库类型

| invtyp | 类型 | 用途 |
|--------|------|------|
| 5 | 借出归还入库 | 借出物品归还 |
| 6 | 翻新入库 | 翻新完成后的设备入库 |
| 7 | 回收入库 | 回收件入库 |
| 8 | 其他入库 | 质检入库、生产入库等 |

## 三、出库管理

### 3.1 退货出库（invtyp=6）

**业务场景**：采购退货单审核通过后，仓库操作员办理退货出库。

**操作步骤**：

1. 打开"出库单管理"页面
2. 点击"新建"按钮
3. 选择出库类型：**退货出库**
4. 选择关联单据号：填写采购退货单号（如 RT000010）
   - 供应商自动带出
5. 选择出库仓库：退货物品当前存放仓库
6. 填写出库明细：
   - 物料编码、数量
   - EID（有设备序列号时填写）
   - 关联行号
7. 点击"保存"生成草稿单
8. 点击"审核"：
   - 系统自动扣减 TWH11/12 库存
   - 系统写入 TWH12 库存流水
   - 系统更新 TPC16 退货状态为已完成

**自动触发**：
- 采购退货单审核通过后，系统会自动生成退货出库草稿（auditflg='0'）
- 仓库操作员只需确认后审核

**注意事项**：
- 退货出库只扣库存，不回减 TPC13.inqty（inqty = 历史累计入库量）
- 退货数量不能超过可退余量（已入库量 - 已退量）

## 四、库存查询

### 4.1 实时库存查询

**功能**：查询当前仓库的库存数量。

**操作步骤**：

1. 打开"库存查询"页面
2. 选择仓库（可选）
3. 输入物料编码（可选）
4. 点击"查询"
5. 查看库存明细：
   - 物料编码、物料名称
   - 仓库编码、仓库名称
   - 库存数量
   - 安全库存上限/下限

---

### 4.2 库存流水查询

**功能**：查询库存变动历史记录（TWH12）。

**操作步骤**：

1. 打开"库存流水"页面
2. 选择仓库（可选）
3. 输入物料编码（可选）
4. 选择日期范围（可选）
5. 输入单据号（可选）
6. 点击"查询"
7. 查看流水明细：
   - 变动日期
   - 单据号
   - 入库/出库类型
   - 变动数量
   - 库存余量
   - 操作员

## 五、盘点管理

### 5.1 资产盘点

**功能**：对仓库资产进行盘点，记录盘点结果。

**操作步骤**：

1. 打开"资产盘点"页面
2. 点击"新建"按钮
3. 填写盘点单信息：
   - 盘点仓库
   - 盘点日期
   - 盘点类型
4. 填写盘点明细：
   - 物料编码
   - 账面数量
   - 实盘数量
   - 差异数量（自动计算）
5. 保存并审核

---

### 5.2 盘盈盘亏

**功能**：处理盘点后的盘盈盘亏。

**操作步骤**：

1. 打开"盘盈盘亏"页面
2. 点击"新建"按钮
3. 填写损益单信息：
   - 仓库
   - 类型（盘盈/盘亏）
   - 原因
4. 填写损益明细：
   - 物料编码
   - 数量
   - EID（设备序列号）
5. 保存并审核

**审核后**：
- 盘盈：增加库存
- 盘亏：减少库存

## 六、报表分析

### 6.1 收发存汇总

**功能**：按仓库×物料×月份统计期初库存、本期入库、本期出库、期末库存。

**操作步骤**：

1. 打开"收发存汇总"页面
2. 选择仓库（可选）
3. 选择月份（默认当月）
4. 点击"查询"
5. 查看汇总数据：
   - 期初库存（月初库存）
   - 本期入库数量
   - 本期出库数量
   - 期末库存（期初 + 入库 - 出库）

**公式**：
```
期末库存 = 期初库存 + 本期入库 - 本期出库
```

---

### 6.2 库存日报

**功能**：查询指定日期的库存变动快照。

**操作步骤**：

1. 打开"库存日报"页面
2. 选择仓库（可选）
3. 选择日期（默认当天）
4. 点击"查询"
5. 查看日报数据：
   - 当日入库数量
   - 当日出库数量
   - 当日末库存快照

---

### 6.3 库龄分析

**功能**：分析物料在库时间，识别呆滞库存。

**操作步骤**：

1. 打开"库龄分析"页面
2. 选择仓库（可选）
3. 点击"查询"
4. 查看库龄数据：
   - 物料编码
   - 当前库存数量
   - 首次入库日期
   - 在库天数

**说明**：
- 在库天数 = 当前日期 - 首次入库日期
- 这是简化方案，非 FIFO 批次库龄
- 用于识别长期未动的呆滞物料

## 七、审核操作

### 7.1 入库单审核

**操作步骤**：

1. 在入库单列表中，找到待审核的单据（审批状态=未审核）
2. 点击"审核"按钮
3. 弹出审核弹窗，显示单据信息：
   - 单号、关联单据
   - 仓库、类型
   - 入库明细
4. 填写审核备注（可选）
5. 点击"审核通过"或"退回"

**审核通过后**：
- 更新库存（TWH11/12）
- 写入库存流水（TWH12）
- 采购入库时更新 TPC13.inqty
- 采购入库时更新 TPC20 linkstatus

---

### 7.2 出库单审核

**操作步骤**：

1. 在出库单列表中，找到待审核的单据（审批状态=未审核）
2. 点击"审核"按钮
3. 弹出审核弹窗，显示单据信息：
   - 单号、关联单据
   - 仓库、类型
   - 出库明细（PRD/EID）
4. 填写审核备注（可选）
5. 点击"审核通过"或"退回"

**审核通过后**：
- 扣减库存（TWH11/12）
- 写入库存流水（TWH12）
- 退货出库时更新 TPC16 状态

## 九、自动生成 vs 手动新建

| 场景 | 方式 | 触发条件 |
|------|------|---------|
| 采购入库 | 🖐 手动 / 🚀 自动 | 自动：订单审核通过后生成草稿（whcd留空） |
| 退货出库 | 🖐 手动 / 🚀 自动 | 自动：退货单审核通过后生成草稿 |
| 调拨入库 | 🖐 手动 | 无上游触发 |
| 调拨出库 | 🖐 手动 | 无上游触发 |
| 服务返还/领用 | 🖐 手动 | 待ITSM模块联动 |
| 质检入库/出库 | 🖐 手动 | 待质检模块联动 |
| 其他入库/出库 | 🖐 手动 | 无上游触发 |

> 自动生成的草稿 `whcd` 为空，审核时必须选择仓库。

## 十、注意事项

### 10.1 数据一致性

- **入库数量 ≤ 订购数量**：采购入库时，实际入库数量不能超过订购数量
- **出库数量 ≤ 库存数量**：出库时，数量不能超过当前库存
- **退货数量 ≤ 可退余量**：退货数量不能超过（已入库量 - 已退量）

### 10.2 审核状态

- **未审核（0）**：草稿状态，可编辑、可删除
- **待审核（1）**：已送审，不可编辑
- **已审核（2）**：审核通过，不可修改
- **已退回（9）**：审核退回，可重新编辑后送审
- **已作废（V）**：作废单据，不可操作

### 10.3 EID 设备追踪

- 有 EID 的设备出库时，必须填写 EID
- EID 出库明细和批次出库明细分开存储
- EID 用于设备级追踪，批次用于数量级管理

### 10.4 关联单据

- 采购入库必须关联采购订单号
- 退货出库必须关联采购退货单号
- 服务入库/出库必须关联 ITSM 工单号
- 关联单据号用于追溯业务来源

## 十一、常见问题

### Q1: 采购订单审核后没有自动生成入库草稿？

**A**: 检查以下条件：
- 采购订单审核状态是否为"已审核"
- 系统日志是否有异常（查看 `warehouse_service.py` 日志）
- 供应商编码是否正确

### Q2: 入库审核后库存没有更新？

**A**: 检查以下条件：
- 审核状态是否为"已审核"
- 入库明细数量是否大于 0
- 仓库编码是否正确
- 查看 TWH12 库存流水是否有记录

### Q3: 退货出库时提示"超过可退余量"？

**A**: 检查以下条件：
- 该订单行的已入库量
- 该订单行的已退量
- 可退余量 = 已入库量 - 已退量
- 退货数量不能超过可退余量

### Q4: 库存流水查询不到数据？

**A**: 检查以下条件：
- 是否有入库/出库审核通过的记录
- 日期范围是否正确
- 仓库/物料筛选条件是否正确
