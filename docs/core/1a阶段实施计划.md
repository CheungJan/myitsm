### D8: warranty_expire 派生回填

**规则**：`warranty_expire = install_date + (old_degree='12' ? newperiod : oldperiod)`

**SQL**：

```sql
-- 回填 tmm43_eid.warranty_expire（仅对有 install_date 的设备）
UPDATE tmm43_eid e
SET warranty_expire = e.install_date + MAKE_INTERVAL(days =>
    CASE WHEN e.old_degree = '12' THEN COALESCE(i.newperiod, 0)
         ELSE COALESCE(i.oldperiod, 0)
    END)
FROM tmm12_items i
WHERE e.itemcd = i.item_cd
  AND e.install_date IS NOT NULL
  AND e.warranty_expire IS NULL;

-- 验证回填结果
SELECT
    CASE WHEN warranty_expire IS NOT NULL THEN '已回填'
         WHEN install_date IS NULL THEN '无安装日期(不回填)'
         ELSE '有安装日期未回填'
    END AS 状态,
    COUNT(*) AS 设备数
FROM tmm43_eid
GROUP BY 1;
```

**验收**：
- 有 `install_date` 的设备 `warranty_expire` 已回填
- 无 `install_date` 的设备 `warranty_expire` 为 NULL（后续关单 L2 补写）

```python
def resolve_entitlement(eid: Eid, cust_pos_rl: CustPosRl) -> Entitlement:
    """判定设备当前服务权益（6 级优先级，对齐行业 EAM/FSM）。

    调用示例（关单联动中）：
        eid = db.session.get(Eid, accessories_update.new_accessories_id)
        cust_pos_rl = db.session.query(CustPosRl).filter_by(eid=eid.eid).first()
        entitlement = resolve_entitlement(eid, cust_pos_rl)

    优先级：
      1. 特殊客户协议 — 最高优先，覆盖所有规则
      2. 维保合同 — 客户购买的维保服务
      3. 租赁/借用/免费投放/合作运营 — 公司承担
      4. 厂家保修 — warranty_expire 判定
      5. Owner 默认规则 — asset_owner 兜底
      6. 异常兜底 — 默认收费
    """
    business_mode = cust_pos_rl.business_mode if cust_pos_rl else None
    asset_owner = eid.asset_owner
    now = datetime.now()

    # 1. 特殊客户协议（最高优先）
    special = get_special_agreement(cust_pos_rl.cust_cd)
    if special:
        return Entitlement(free=special['is_free'], reason=f"特殊协议: {special['name']}")

    # 2. 维保合同
    contract = get_service_contract(eid.eid)
    if contract:
        return Entitlement(free=contract['is_free'], reason=f"维保合同: {contract['name']}")

    # 3. 租赁/借用/免费投放/合作运营 → 公司承担
    if business_mode in ('02', '03', '07', '08'):
        return Entitlement(free=True, reason=f"{BM_S_DICT.get(business_mode, '未知')}，公司承担")

    # 4. 厂家保修（销售/寄售/试用模式按保修期判定）
    if business_mode in ('01', '05', '06'):
        if eid.warranty_expire and now <= eid.warranty_expire:
            return Entitlement(free=True, reason="保内")
        return Entitlement(free=False, reason="过保")

    # 5. Owner 默认规则（存量数据无 business_mode 时兜底）
    if asset_owner == '01':  # 商用电子
        return Entitlement(free=True, reason="商用电子（默认免费）")
    if asset_owner == '04':  # 海晟
        return Entitlement(free=False, reason="海晟（按合同，无合同默认收费）")

    # 6. 异常兜底
    return Entitlement(free=False, reason="门店资产（默认收费）")
```

```python
def resolve_service_responsibility(eid: Eid) -> str:
    """派工默认服务责任方（SR 字典）。

    推导规则：
      - 厂商保修期内（warranty_expire > now）→ '02' 厂商
      - 海晟设备（asset_owner='04'）→ '03' 代维
      - 其他 → '01' 内部（默认）
    """
    now = datetime.now()

    # 厂商保修期内 → 厂商处理
    if eid and eid.warranty_expire and now <= eid.warranty_expire:
        return '02'  # 厂商

    # 海晟设备 → 代维
    if eid and eid.asset_owner == '04':
        return '03'  # 代维

    # 其他 → 内部
    return '01'  # 内部
```

### C6: 旧件处理策略（§3.5.6）

```python
def _resolve_old_part_disposal(self, eid: str, entitlement: Entitlement) -> str:
    """旧件处理策略（基于 Entitlement + Ownership 双维度）。

    返回值：'recycle' 入库回收 / 'scrap' 报废 / 'contract' 按代维合同
    """
    eid_record = db.session.get(Eid, eid)
    asset_owner = eid_record.asset_owner if eid_record else None

    # 保内 → 入库回收（厂商/公司赔付）
    if entitlement.free and '保内' in entitlement.reason:
        return 'recycle'

    # 过保按 asset_owner 判定
    if asset_owner == '01':  # 商用电子
        return 'recycle'  # 公司承担
    if asset_owner == '03':  # 门店资产
        return 'scrap'  # 客户承担，in_wh='2'
    if asset_owner == '04':  # 海晟
        return 'contract'  # 按代维合同

    return 'scrap'  # 默认报废
```

- 过保门店资产设备旧件报废（`in_wh='2'`）

```python
def _write_back_plan_status(self, planno: str):
    """L8：回写预计划状态 + PF→OW 映射。"""
    plan = self._get_plan(planno)
    if not plan:
        return

    # 原有逻辑：回写 plan_status
    plan.plan_status = '03'  # 实施完成

    # 1a 新增：PF→OW 映射
    pos_from = plan.pos_from
    eid = plan.posid
    if eid:
        if pos_from == '00':  # 商用仓库 → 商用电子
            self._update_asset_owner(eid, '01')
        elif pos_from == '03':  # IT公司 → 通方信息
            self._update_asset_owner(eid, '02')
        elif pos_from == '04':  # 海晟公司 → 海晟
```
