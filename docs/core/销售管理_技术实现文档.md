# 销售管理（预计划）— 技术实现文档

> 涵盖预计划全链路编排、客户生命周期、呼出单、押金联动、销售出库。

## 1. 架构概览

```
API 层    app/api/sales.py        15 端点（预计划/呼出单/销售单据/延期）
────────────────────────────────────────────────────
服务层    app/services/sales_service.py    PlanCustService / PlanServeService
          app/services/customer_service.py  CustomerService
          app/services/deposit_service.py   押金联动
────────────────────────────────────────────────────
仓储层    app/repositories/sales_repository.py  PlanCustRepo / PlanServeRepo
────────────────────────────────────────────────────
模型层    app/models/sales.py    PlanCust / PlanServe / SalesBill / SalesExtend
```

## 2. 核心数据模型

### 2.1 PlanCust（plan_cust）

| 字段 | 类型 | 说明 |
|------|------|------|
| `planno` | VARCHAR(10) PK | 计划编号 |
| `plantyp` | VARCHAR(2) | 00新机开通/10设备变更/20翻新/30取机/40关门 |
| `plan_status` | VARCHAR(2) | 工作流状态（00→01→02→04→09） |
| `imple_billid` | VARCHAR(20) | 下游单据ID（实施确认时写入） |
| `deposit` | NUMERIC(12,2) | 押金金额 |
| `is_rent` | VARCHAR(1) | 是否租赁(Y/N) |
| `is_outflag` | VARCHAR(2) | 出库标志(1=已生成) |

### 2.2 PlanServe（plan_serve）

| 字段 | 类型 | 说明 |
|------|------|------|
| `dtlid` | INTEGER PK AUTO | 明细ID |
| `planno` | VARCHAR(10) FK | 关联预计划 |
| `servetyp` | VARCHAR(2) | 0客户确认/1预计划呼出/2实施任务 |
| `serve_back` | VARCHAR(200) | 客户反馈/呼出结果 |
| `status` | VARCHAR(2) | 00待呼出/01已呼出/09作废 |

## 3. 状态机

### 3.1 预计划工作流（plan_cust.plan_status）

```
00 计划中  ──→ 01 已确认  ──→ 02 实施中  ──→ 04 已完成
  │              │                │
  └──────────────┴────────────────┴──→ 09 已作废
```

**对齐 PB plan_cust.status 实际值分布**（ortopbitsmdb 验证）：00=20条, 01=8102条, 02=116条, 04=161条, 09=1209条。

### 3.2 呼出单（plan_serve.status）

```
00 待呼出  ──→ 01 已呼出  ──→ 09 作废
```

## 4. 核心业务方法

### 4.1 PlanCustService.create()

```
输入: 客户信息 + plantyp + 可选deposit/is_rent
流程:
  1. 磁卡号唯一性检查（Customer + PlanCust 两表）
  2. 创建 plan_cust（plan_status=00）
  3. 自动创建 PlanServe 呼出单（servetyp='0'）
  4. 创建 TEMP 客户（CustomerService）
输出: {"success": True, "planno": "..."}
```

### 4.2 PlanCustService.implement()

```
前置: plan_status=01 + 至少一条 PlanServe.status=01
流程:
  1. 呼出前置校验（无已呼出记录→拒绝）
  2. 幂等检查（imple_billid 已有→拒绝）
  3. plantyp 路由 → ITSM Repository.create()（同一事务）
  4. 回写 imple_billid = 下游单据ID
  5. 押金联动（deposit>0 → tmm61_deposit_dtl）
  6. plan_status 01→02 + 客户 TEMP→PENDING
输出: {"success": True, "downstream_id": "..."}
```

### 4.3 下游单据路由表

| plantyp | Repository | 主键字段 | 表 |
|---------|-----------|---------|-----|
| 00 | MaintenanceOpenRepository | new_opening_id | TIT13 |
| 10 | DeviceChangeRepository | device_change_id | TIT16 |
| 20 | MaintenanceRenovateRepository | renew_id | TIT15 |
| 30 | RecycleTaskRepository | recycle_id | TIT20 |
| 40 | StoreCloseRepository | store_close_id | TIT18 |

### 4.4 PlanCustService.create_outbound()

```
前置: plan_status=02
去重: 同一 planno 已有 OV=1 草稿→拒绝
创建: StockOutService.create(invtyp='1', refbillid=planno)
标记: plan_cust.is_outflag='1'
```

### 4.5 PlanCustService.void()

```
规则:
  - plan_status=04 → 阻止（终态）
  - 级联作废下游 ITSM 草稿（status!=终态 → status=9）
  - 客户 TEMP/PENDING → INVALID
```

## 5. 客户生命周期

```
TEMP ──→ PENDING ──→ ACTIVE
  │         │
  └─────────┴──→ INVALID（作废时）
```

| 触发点 | 变更 |
|--------|------|
| create() | → TEMP |
| transition(00→01) | TEMP → PENDING |
| complete() | PENDING → ACTIVE |
| void() | TEMP/PENDING → INVALID |

## 6. API 端点清单

### 预计划
| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/plans` | 列表（可按 plantyp/plan_status/custcd 过滤） |
| GET | `/plans/<planno>` | 详情 |
| POST | `/plans` | 创建（自动生成 PlanServe + TEMP 客户） |
| PUT | `/plans/<planno>` | 更新（磁卡号同步 Customer） |
| POST | `/plans/<planno>/transition` | 状态流转 |
| POST | `/plans/<planno>/implement` | 实施确认（生成下游 ITSM + 押金） |
| POST | `/plans/<planno>/outbound` | 生成 OV=1 出库草稿 |
| POST | `/plans/<planno>/complete` | 完成（客户→ACTIVE） |
| POST | `/plans/<planno>/void` | 作废（级联 + 客户→INVALID） |

### 呼出单
| 方法 | 路径 | 功能 |
|------|------|------|
| GET | `/plans/<planno>/serve` | 呼出记录列表 |
| POST | `/plans/<planno>/serve` | 创建呼出单 |
| PUT | `/plan-serve/<dtlid>` | 更新呼出结果 |
| POST | `/plan-serve/<dtlid>/transition` | 呼出状态流转 |
| GET | `/plan-serve` | 全部呼出单（按 planno 过滤） |

### 销售单据
| 方法 | 路径 | 功能 |
|------|------|------|
| GET/POST | `/bills` | 销售单据列表/创建 |
| POST | `/bills/<id>/audit` | 审核 |

### 延期
| 方法 | 路径 | 功能 |
|------|------|------|
| GET/POST | `/extends` | 延期列表/创建 |
