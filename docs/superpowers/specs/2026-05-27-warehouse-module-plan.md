# 仓库模块重构方案

## 一、核心理念

> "仓库不管什么出入库本质都是从什么仓库到什么仓库，只是对应选择不同业务可能涉及的业务表和变动表情况不一样。"

基于这个理念，仓库模块应该保持当前统一模型设计：**单一入库入口 + invtyp 区分业务类型 + 单一出库入口 + invtyp 区分业务类型**。

---

## 二、当前数据模型（已正确，保持不变）

```
TWH01 — 仓库主数据         TWH11 — 库存汇总 (按物料+仓库)
TWH13 — 入库主表 (统一)     TWH12 — 库存明细 (按物料+仓库+批次)
TWH14 — 入库明细           TWH17 — 盘盈盘亏主表
TWH15 — 出库主表 (统一)     TWH18 — 盘盈盘亏明细
TWH16 — 出库明细(EID+PRD)  TWH19 — 资产盘点主表
                           TWH20 — 资产盘点明细
                           TWH21 — 货位变更主表
                           TWH22 — 货位变更明细
```

### 入库类型 (TWH13.invtyp)

| invtyp | 业务 | PB 窗口 | 上游触发单据 |
|--------|------|---------|------------|

## 五、统一出入库设计原则

### 5.1 页面结构

```
仓库管理
├── 入库管理 (统一入口，invtyp 下拉选择业务类型)
│   ├── 采购入库 (invtyp=1) — 关联采购订单
│   ├── 销售退货入库 (invtyp=2)
│   ├── 服务返还入库 (invtyp=3)
│   ├── 调拨入库 (invtyp=4) — 选择来源仓库
│   ├── 借出归还入库 (invtyp=5)
│   ├── 翻新入库 (invtyp=6)
│   ├── 回收入库 (invtyp=7)
│   └── 其他入库 (invtyp=8)
│
├── 出库管理 (统一入口，invtyp 下拉选择业务类型)
│   ├── 销售出库 (invtyp=1) — 关联销售订单
│   ├── 服务领用出库 (invtyp=2) — 关联 ITSM 工单
│   ├── 调拨出库 (invtyp=3) — 选择目标仓库
│   ├── 借出出库 (invtyp=4)
│   ├── 质检出库 (invtyp=5) — 关联采购入库单
│   ├── 退货出库 (invtyp=6) — 关联采购退货单
│   ├── 报废出库 (invtyp=7)
│   └── 其他出库 (invtyp=8)
│
├── 库存查询 — 按仓库/物料/批次查询 TWH11/12
├── 货位变更 — TWH21/22
├── 资产盘点 — TWH19/20
└── 盘盈盘亏 — TWH17/18
```

### 5.2 入库表单统一结构

```
┌─ 入库单 ─────────────────────────────────────┐
│ 入库类型: [采购入库 ▼]        ← invtyp       │
│ 入库仓库: [01 新品库 ▼]       ← whcd         │
│ 来源单号: [PR001217       ]   ← refbillid    │
│ 供应商:   [自动带出/手动选择]   ← suppcd      │
│ 入库日期: [2026-05-27    ]                    │
│                                               │
│ ┌─ 入库明细 ──────────────────────────────┐  │
│ │ 物料编码  数量  批次号  单价  来源行号    │  │
│ │ MB7000    50    LOT-A   560   1         │  │
│ │ MT7000    50    LOT-A   180   2         │  │
│ └─────────────────────────────────────────┘  │
│                                               │
│ 备注: [                        ] [保存] [审核]│
└───────────────────────────────────────────────┘
```

不同 invtyp 的差异：
- invtyp=1 (采购入库): 来源单号=采购订单号，供应商自动带出，明细可关联订单行
- invtyp=3 (服务返还): 来源单号=ITSM 工单号
- invtyp=4 (调拨入库): 来源单号=调拨出库单号，供应商不显示
- 其他类型：来源单号手动填写或为空

### 5.3 出库表单统一结构

```
┌─ 出库单 ─────────────────────────────────────┐
│ 出库类型: [退货出库 ▼]        ← invtyp       │
│ 出库仓库: [04 生产配件库 ▼]   ← whcd         │
│ 来源单号: [RT000001       ]   ← refbillid    │
│ 出库日期: [2026-05-27    ]                    │
│                                               │
│ ┌─ 出库明细 (按物料+批次) ────────────────┐  │
│ │ 物料编码  数量  批次号  来源行号          │  │
│ │ MB7000    2     LOT-A   1               │  │
│ └─────────────────────────────────────────┘  │
│                                               │
│ ┌─ 出库明细 (按 EID) ────────────────────┐   │
│ │ EID          物料    序列号             │   │
│ │ 20231000001  MB7000  SN20231000001     │   │
│ └─────────────────────────────────────────┘  │
│                                               │
│ 备注: [                        ] [保存] [审核]│
└───────────────────────────────────────────────┘
```

## 六、关键业务流程

### 6.1 采购入库流程

```
采购订单审核通过
    │
    └── 仓库操作员：打开入库管理 → 选择 invtyp=1 (采购入库)
        选择来源订单号 (refbillid=rgstbillid)
        系统自动带出订单明细 (物料/数量/单价)
        填写实际入库数量、批次号
        选择入库仓库
        保存 → 审核
            │
            ├── 更新 TPC13.inqty += 入库数量
            ├── 更新 TWH11/12 库存 (物料+仓库+数量)
            ├── 更新 TPC20.linkstatus (ordered → partial_in/completed)
            └── 触发质检流程 (生成质检出库单)
```

### 6.2 退货出库流程

```
采购退货单审核通过
    │
    └── 仓库操作员：打开出库管理 → 选择 invtyp=6 (退货出库)
        选择来源退货单号 (refbillid=return_id)
        系统自动带出退货明细
        确认出库数量
        选择出库仓库
        保存 → 审核
            │
            ├── 更新 TPC13.inqty -= 出库数量
            ├── 更新 TWH11/12 库存 (物料+仓库-数量)
            └── 更新 TPC16 退货状态
```

### 6.3 质检流程（仓库视角）

```
采购入库完成
    │
    └── 质检出库 (invtyp=5): 从仓库移出到质检区
        │
        └── 质检结果 (TQC10/11)
            │
            ├── 合格 → 质检入库 (invtyp=3): 从质检区移入合格品库
            │
            └── 不合格 → 退货出库 (invtyp=6): 从质检区退回供应商
```
