# 前端空白页故障分析报告

## 故障现象

前端访问 `http://localhost:3000/` 显示空白页面。

## 根因分析

### 直接原因：Vite 代理目标端口与 Flask 实际端口不一致

```
vite.config.ts 代理配置        实际 Flask 进程
target: http://127.0.0.1:5000  →  Flask 运行在 127.0.0.1:5001
```

前端所有 `/api/*` 请求被代理到 5000 端口，但 Flask 在 5001 端口。请求全部失败（ECONNREFUSED），前端无法获取任何数据，页面渲染为空白。

### 间接原因：macOS AirPlay Receiver 占用 5000 端口

```bash
$ lsof -i :5000
COMMAND    PID USER   FD   TYPE DEVICE SIZE/OFF NODE NAME
ControlCe 58932 cheungjan 11u IPv4 ... TCP *:commplex-main (LISTEN)
```

macOS Ventura+ 默认开启的 AirPlay Receiver 占用 TCP 5000 端口，Flask 无法绑定到此端口。

### 触发链路

```
1. 开发过程中多次重启 Flask/Vite
2. Flask 默认端口 5000 被 AirPlay 占用 → 启动失败
3. 改用 5001 端口启动 Flask 成功
4. 但 vite.config.ts 仍指向 5000（被手动或 lint 工具回改）
5. 代理断连 → 空白页
```

### 附带问题

| 问题 | 现象 | 原因 |
|------|------|------|
| Flask debug reloader 崩溃 | `termios.error: (4, 'Interrupted system call')` | `flask run --debug` 的 werkzeug reloader 在 nohup 后台模式不兼容 |
| Vite 未从正确目录启动 | `npm warn exec ... will be installed: vite@8.0.14` | `nohup npx vite` 在非 frontend 目录执行，找不到本地 vite |

## 解决方案

### 永久修复

**1. 固定 Flask 端口为 5001**

在项目根目录创建 `.env` 文件：

```bash
FLASK_RUN_PORT=5001
```

或在 `.flaskenv` 中：

```
FLASK_RUN_PORT=5001
```

**2. 固定 Vite 代理端口为 5001**

`frontend/vite.config.ts` 已修改为：

```ts
proxy: {
    '/api': {
        target: 'http://127.0.0.1:5001',
        changeOrigin: true
    }
}
```

**3. 关闭 macOS AirPlay Receiver（可选）**

系统设置 → 通用 → AirDrop 与 Handoff → AirPlay 接收器 → 关闭

或者保持关闭，继续使用 5001 端口。

### 标准启动命令

```bash
# ===== 后端 =====
# 关闭
pkill -f "flask run"

# 启动（后台模式，不加 --debug 避免 reloader 崩溃）
cd /Users/cheungjan/myitsm && nohup uv run flask run --port 5001 > /tmp/flask.log 2>&1 &

# ===== 前端 =====
# 关闭
pkill -f "vite"

# 启动（必须在 frontend 目录下）
cd /Users/cheungjan/myitsm/frontend && nohup npx vite --host > /tmp/vite.log 2>&1 &

# ===== 验证 =====
curl -s http://127.0.0.1:5001/api/v1/health  # 后端健康检查
curl -s http://localhost:3000/ | head -5       # 前端 HTML 响应
```

### 故障快速排查清单

| 检查项 | 命令 | 正常结果 |
|--------|------|---------|
| Flask 进程 | `pgrep -f "flask run"` | 有 PID 输出 |
| Vite 进程 | `pgrep -f "vite"` | 有 PID 输出 |
| Flask 端口 | `lsof -i :5001 \| grep LISTEN` | Python 进程监听 |
| 后端连通性 | `curl -s http://127.0.0.1:5001/api/v1/health` | `{"code":200,...}` |
| 前端连通性 | `curl -s http://localhost:3000/ \| head -3` | `<!doctype html>` |
| 代理连通性 | `curl -s http://localhost:3000/api/v1/health` | `{"code":200,...}` |
| 端口冲突 | `lsof -i :5000` | 不应有 Flask 进程 |

### 防范措施

1. **不要来回改端口**：项目统一使用 5001，.env 和 vite.config.ts 同步
2. **启动前检查端口**：`lsof -i :5001` 确认无残留进程
3. **变更端口后同步改两处**：`.env`（或启动参数）和 `vite.config.ts`
4. **后台模式不加 `--debug`**：避免 werkzeug reloader 崩溃，开发时如需 debug 在前台运行
