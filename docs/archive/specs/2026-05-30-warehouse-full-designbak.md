## 1. 设计原则

### 1.1 核心原则

```
所有出入库操作必须关联上游业务单据。
能自动生成就自动生成，不能自动的通过单据选择器关联。
禁止无来源的裸填物料编码/EID。
```

### 1.2 出入库本质

> 出入库 = 设备仓库变更 + 设备状态变更

每次出入库操作同时影响：
- **仓位**：设备从A仓移到B仓（`TMM43_EID.whcd`、`TWH11_DETAIL`）
- **状态**：设备状态流转（`TMM43_EID.sflg`、`TMM43_EID.qcflg`）

### 1.3 自动联动优先级

```
上游单据审核通过
    │
    ├─ 能确定仓库+明细 → 完全自动生成 + 自动审核
    ├─ 能确定明细但仓库待定 → 生成草稿，人工选仓库后审核
    └─ 不能自动的 → 提供单据选择器，选单后自动填明细
```

## 3. 批次模式 vs EID模式

### 3.1 概念

PB 通过 `optyp` 字段区分两种操作模式：

| optyp | 模式 | 明细表 | 适用对象 | 操作方式 |
|-------|------|--------|---------|---------|
| `PC` | 批次出库 | TWH16_OUTDTPRD | 无EID的散料/来料 | 按物料编码+数量 |
| `ID` | EID出库 | TWH16_OUTDTEID | 有EID的设备/配件 | 按EID精确追踪 |

入库同理，`TWH14_CHECKINDT` 同时承载两种模式（通过 `eid` 字段是否为空区分）。

### 3.2 模式选择规则

| 物料类型 | 模式 | 说明 |
|---------|------|------|
| 整机（POS机等） | EID | 每台有唯一序列号 |
| 关键配件（读卡器、主板等） | EID | 有EID需精确追踪 |
| 散料（线材、螺丝等） | 批次 | 无EID，按数量管理 |
| 包装/耗材 | 批次 | 无需精确追踪 |

### 3.3 待实现

```python
# TWH13_IN / TWH15_OUT 增加字段
optyp = db.Column(db.String(2), comment="操作方式: PC=批次, ID=EID")

# TWH14_CHECKINDT 增加字段
optyp = db.Column(db.String(2), comment="操作方式: PC=批次, ID=EID")
```

## 4. 自动联动规则

### 4.1 规则总表

| 触发事件 | 自动生成 | invtyp | 草稿/直接审核 | 条件 |
|---------|---------|--------|:--:|------|
| 采购订单审核 | 采购入库草稿 | in=1 | 草稿(whcd=空) | auditflg='2' |
| 退货单审核 | 退货出库草稿 | out=6 | 草稿 | auditflg='2' |
| 配件变更确认 | 服务返还入库 | in=3 | 草稿 | operflg='1' |
| 调拨出库审核 | 调拨入库草稿 | in=4 | 草稿 | auditflg='2' |
| 质检合格审核 | 质检入库草稿 | in=7 | 草稿 | qcflg='合格' |
| 采购入库审核 | 质检出库草稿 | out=5 | 草稿 | 需要质检的物料 |

### 4.2 草稿更新规则（已实现）

手动新建时如果已有未审核草稿，**更新草稿**而非新建：
- 采购入库手动新建 → 更新已有采购入库草稿
- 退货出库手动新建 → 更新已有退货出库草稿

## 5. 各业务场景详细设计

### 5.1 采购入库 (in=1) ✅ 已完成

```
采购订单审核(TPC12)
    │
    ├─ 自动生成采购入库草稿 (whcd=""，待填仓库)
    │
    └─ 手动路径：选择采购订单 → 自动填明细 → 保存
           │ 如果已有草稿 → 更新草稿
           │ 如果无草稿 → 新建
           │
           ▼
         审核入库 → TWH11+ TWH12+ TPC13.inqty+ TPC20.linkstatus
```

### 5.2 退货出库 (out=6) ✅ 已完成

```
退货单审核(TPC16)
    │
    ├─ 自动生成退货出库草稿 (whcd=L1)
    │
    └─ 手动路径：选择退货单 → 自动填明细 → 仓库默认L1
           │ 填EID → 自动查EID所在仓 → 覆盖仓库字段
           │ 审核 → 校验库存 → TWH11- TWH12+ TMM43_EID.whcd清空
```

### 5.3 服务返还入库 (in=3) ⚠️ 待完善

**业务场景**：ITSM维护工单更换下来的自有资产旧配件返还仓库

**PB流程**：
```
ITSM维护单配件更换完成
    ↓
写入SM_IN_PART_CHANGE（sys_status=2, operflg=1）
    ↓
CCGL数据确认模块 → 用户确认
    ↓
自动创建维护入库单（TWH13, invtyp='3', refbillid=SM_IN_PART_CHANGE.ID）
    ↓
更新TMM43_EID（工程师仓库 → 正式仓库，qcflg='待检'）
```

**待实现**：
1. 建立"数据确认"页面：查询 TIT25（operflg='1' 且未确认）+ TMM43_EID（asset_owner != '01'）
2. 用户点击"确认入库"→ 自动生成服务返还入库草稿
3. 关联单据：refbillid = TIT25.id
4. 仓库操作员审核入库 → 更新 TMM43_EID.whcd + qcflg='待检'

**当前临时方案**：已实现基于 TIT25 的可返还查询，手动选择 ITSM 工单填充。

### 5.4 调拨出入库 (out=3 → in=4) ❌ 待实现

### 5.5 质检出入库 (out=5 → in=7) ❌ 待实现

```
采购入库审核(in=1) → 自动生成质检出库草稿(out=5)
    ├─ refbillid = 采购入库单号
    └─ 从待检仓移出到质检库
    ↓
质检结果审核(qcflg='合格')
    ↓
自动生成质检入库草稿(in=7)
    ├─ refbillid = 质检结果单号
    └─ 从质检库移入正式仓库

```

### 5.6 生产出入库 (out=7 → in=6) — 手动，依赖MES

当前 MES 模块尚未对接，生产出入库为手动创建，`refbillid` 填写 MES 工单号备查。

PB 中支持按 BOM 自动计算配件清单，待 MES 对接后实现。

### 5.7 借出归还 (out=4 → in=5) — 手动

借出出库和归还入库均为手动，归还入库关联借出出库单号。需考虑：
- 借出期限和借出人字段
- 样品可能没有EID（批次模式）

### 5.8 返修出入库 (out=9 → in=9)

```
质检不合格 / ITSM判定需返修
    ↓
返修出库(out=9) → 关联质检单号/ITSM单号
    ├─ TMM43_EID.whcd = None（送修中）
    └─ TMM43_EID.qcflg = '返修中'
    ↓
返修完成
    ↓
返修入库(in=9) → 关联返修出库单号 → 进入质检库重新质检
```

### 5.9 报废出库 (out=10)

关联质检不合格结果或 ITSM 报废判定，从仓库移出到报废区。需审批流程。

### 5.10 销售退货入库 (in=2) / 销售出库 (out=1)

关联**预计划单号**（plan_cust）。注：2018年4月10日之前的旧数据走销售单（TSL10），之后统一走预计划。

待与销售模块对接后实现自动联动。

## 6. 出入库上游单据选择器

每种出入库类型都应该通过**选择上游单据**来填充明细，而非手动输入。

### 6.1 选择器总表

| 类型 | 选择器 | 查询接口 | 已实现 |
|------|--------|---------|:--:|
| 采购入库 | 选择采购订单 | GET /stock-in/receivable-orders | ✓ |
| 退货出库 | 选择退货单 | GET /stock-out/returnable-orders | ✓ |
| 服务返还入库 | 选择ITSM配件变更 | GET /stock-in/service-returnable | ⚠ |
| 调拨入库 | 选择调拨出库单 | GET /stock-in/transferable-orders | ✗ |
| 借出归还入库 | 选择借出出库单 | GET /stock-in/lendable-orders | ✗ |
| 质检入库 | 选择质检结果单 | GET /stock-in/qc-passed | ✗ |
| 质检出库 | 选择采购入库单 | GET /stock-out/qc-pending | ✗ |
| 销售退货入库 | 选择预计划 | GET /stock-in/sales-returnable | ✗ |

### 6.2 选择器交互规范

```
选择类型 → 显示对应单据下拉框
    │
    ├─ 下拉显示：单号 + 关键信息 + 待处理数量
    ├─ 选中后自动填充：明细行 + 关联单据号
    ├─ 编辑时可手动调整数量（不超过可处理上限）
    └─ 保存时复用已有草稿（不浪费单号）
```
