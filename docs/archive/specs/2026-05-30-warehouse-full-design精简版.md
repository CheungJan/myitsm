# 仓库模块出入库联动设计 v5.1

> 状态: 实施中 | 2026-06-01 | 作者: CJ

## 1. 设计原则

```
所有出入库操作优先关联上游业务单据。
能自动生成就自动生成，不能自动的通过单据选择器关联。
无上游单据时：选仓→库存列表→搜索→勾选出库（批次/EID双模式）。
```

## 3. 自动联动规则

| 触发事件 | 自动生成 | 类型 | 说明 |
|---------|---------|------|------|
| 采购订单审核 | 采购入库草稿 | IV=1 | whcd=空，待填仓库 |
| 退货单审核 | 退货出库草稿 | OV=6 | whcd=L1 |
| 调拨出库审核 | 调拨入库草稿 | IV=4 | whcd=目标仓，明细复制 |
| ITSM配件变更确认 | 服务返还入库草稿 | IV=3 | whcd=空，一键确认 |
| 质检出库 | — | OV=5 | 不自动生成，通过选择器手动触发 |

## 4. 服务返还入库（IV=3）数据流

```
ITSM配件变更 → TIT25_ACCESSORIES_UPDATE
    │  字段对应: SM_IN_PART_CHANGE → TIT25
    │  sys_status→auditflg, operflg→in_wh
    │
    ├─ changetype 从 maintenance_id 前缀推导：
    │   MD→更换, MO→整机, MR→调换
    │
    └─ 入库单管理→服务返还入库→下拉选ITSM工单
         │  五层过滤:
         │  ①in_wh!='1'已入库 ②in_wh!='2'不入库
         │  ③asset_owner!='01'客户 ④consume!='1'耗材
         │  ⑤EID在TMM43中存在
         │
         ├─ [确认入库] → in_wh='1' + 生成入库草稿(IV=3)
         └─ [不入库] → in_wh='2' + 填写原因
```

## 5. 库存浏览（手动模式）

选仓库后出现仓库存量面板：
- 批次模式：物料+SS状态标签+数量
- EID模式：序列号+QC质检标签（数量=1强制锁定）
- 切换仓库自动清空已选明细
- 调拨出库选目标仓，审核生成入库草稿
