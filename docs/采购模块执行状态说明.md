# 采购模块执行状态说明

## 1. 概述

采购流程中有三个地方涉及"状态"，追踪的是采购链路的不同阶段：

```
采购需求 → 采购订单 → 货物入库
  ↑           ↑          ↑
需求状态    订单状态    入库状态
```

---

## 2. 采购需求执行状态

**数据来源**：`v_requisition_execution` 视图  
**追踪对象**：需求行的全生命周期（需求→订单→入库）

| 状态 | 触发条件 | 含义 |
|------|----------|------|
| **未开始** | `ordered_qty = 0` | 还没生成任何订单 |
| **已下单** | `ordered_qty > 0` 且 `received_qty = 0` | 已生成订单，货还没到 |
| **执行中** | `received_qty > 0` 且未全部入库 | 部分到货了 |
| **已完成** | `received_qty >= plan_qty` | 全部入库，任务完成 |

**出现位置**：
- 采购需求列表（`PurchasePlanList.vue`）→ 执行状态列 + 筛选下拉
- 需求详情弹窗 → 每行明细的执行状态标签
- 采购订单创建时 → 选需求单时排除已完成

**计划级汇总规则**（多行需求汇总为一条）：
- 全部行 `已完成` → `已完成`
- 全部行 `未开始` → `未开始`
- 全部行 `已下单` → `已下单`
- 其他混合 → `执行中`

---

## 3. 采购订单执行状态

**数据来源**：`tpc13_registerdt` 表（`inqty` vs `rgsqty`）  
**追踪对象**：订单明细的入库进度

| 状态 | 触发条件 | 含义 |
|------|----------|------|
| **未入库** | `SUM(inqty) = 0` | 订单下了，货还没到 |
| **部分入库** | `0 < SUM(inqty) < SUM(rgsqty)` | 到了一部分货 |
| **已完成** | `SUM(inqty) >= SUM(rgsqty)` | 全部到齐 |

**出现位置**：
- 采购订单列表（`PurchaseRegisterList.vue`）→ 执行状态列 + 筛选下拉

---

## 4. 执行看板统计

**数据来源**：`v_requisition_execution` 视图（与采购需求相同）  
**追踪对象**：需求单级别的聚合统计

| 看板指标 | 计算规则 | 含义 |
|----------|---------|------|
| **已完成** | 计划级状态 = `已完成` 的需求单数 | 全部入库的需求 |
| **执行中** | 计划级状态 IN (`已下单`, `执行中`) | 正在进行中的需求 |
| **未开始** | 计划级状态 = `未开始` 的需求单数 | 还没动作的需求 |
| **总计** | 所有需求单数 | 全部需求 |

**出现位置**：执行看板（`RequisitionDashboard.vue`）→ 顶部统计卡片

---

## 5. 关系对照

```
需求状态          订单状态          看板统计
────────────────────────────────────────────
未开始 ────→ 生成订单后 → 已下单
已下单 ────→ (订单侧)   → 未入库    → 执行中
执行中 ────→ (订单侧)   → 部分入库   → 执行中
已完成 ────→ (订单侧)   → 已完成    → 已完成
```

---

## 6. 审批状态与作废

审批状态（`auditflg`）追踪**工作流**，与执行状态独立。

| 编码 | 含义 | 适用模块 | 操作权限 |
|------|------|---------|---------|
| 0 | 未送审 | 需求 / 订单 | 创建者可送审、作废 |
| 1 | 待审核 | 需求 / 订单 | 审批人可审核 |
| 2 | 已审核 | 需求 / 订单 | 不可退回修改 |
| 9 | 退回 | 需求 / 订单 | 创建者可编辑后重新送审、可作废 |

**作废**（`useflg='9'`）是独立于审批状态的逻辑删除：
- 作废后订单从列表隐藏（`list_by_filters` 过滤 `useflg != '9'`）
- 作废时自动删除 TPC20 关联，释放占用的需求余额
- 已审核通过的订单（`auditflg='2'`）不允许作废

**审批状态筛选**：审批状态从字典表 `AF` 动态获取，筛选下拉自动包含所有状态选项。已作废订单不显示，无需单独筛选。
