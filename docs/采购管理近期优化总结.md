# 采购管理近期优化总结

## 1. 采购订单审核数量简化

**改动前**：审核人可以手动调整每行审核数量  
**改动后**：审核只做通过/退回，审核数量自动等于采购数量

| 改动点 | 文件 |
|--------|------|
| 前端去掉审核数量输入框 | `PurchaseRegisterList.vue` |
| 后端通过时自动 `auditqty = rgsqty` | `procurement_service.py` |
| 编辑驳回订单时同步调减需求审核量 | `procurement_service.py` |

---

## 2. 驳回订单编辑与作废

**编辑**：驳回订单（auditflg='9'）可打开预填弹窗，修改数量后保存并重置为未送审  
**作废**：未送审/退回订单可作废，释放 TPC20 关联占用的需求余额

| 端点 | 方法 | 说明 |
|------|------|------|
| `PUT /orders/<id>` | 编辑 | 更新主表+明细数量+TPC20+需求审核量 |
| `POST /orders/<id>/void` | 作废 | 删 TPC20 关联 + useflg='9' |

**操作栏按钮**：

| auditflg | 可用操作 |
|----------|---------|
| 0（未送审） | 送审、作废 |
| 1（待审核） | 审核 |
| 2（已审核） | — |
| 9（退回） | 编辑、重新送审、作废 |
| useflg=9 | 无操作（已作废） |

## 3. 执行状态体系

### 3.1 采购需求执行状态

| 状态 | 条件 | 含义 |
|------|------|------|
| 未开始 | 全部行 ordered_qty = 0 | 没生成任何订单 |
| 已下单 | 全部行 ordered_qty > 0 且 received_qty = 0 | 已下单但没到货 |
| 执行中 | 混合状态或部分入库 | 各行状态不一致 |
| 已完成 | 全部行 received_qty >= plan_qty | 全部入库 |

**计划级汇总规则**（一个需求单多行 → 一个计划状态）：
- 全部行 `已完成` → `已完成`
- 全部行 `未开始` → `未开始`  
- 全部行 `已下单` → `已下单`
- 其他混合 → `执行中`

### 3.2 采购订单执行状态

| 状态 | 条件 | 含义 |
|------|------|------|
| 未入库 | 全部行 inqty = 0 | 货还没到 |
| 部分入库 | 0 < SUM(inqty) < SUM(rgsqty) | 到了一部分 |
| 已完成 | SUM(inqty) >= SUM(rgsqty) | 全部到齐 |

### 3.3 两个维度的关系

需求执行状态和订单执行状态追踪的是采购链路的不同阶段，互不依赖：
- 需求状态追：需求→订单→入库（全链路）
- 订单状态追：订单→入库（后半段）

## 4. 采购看板

页面由"执行看板"改名为"采购看板"。

### 4.1 采购需求统计

五个互斥指标卡片，支持点击下钻查看明细：

| 卡片 | 说明 |
|------|------|
| 需求总数 | 所有有效需求单 |
| 已完成 | 全部入库 |
| 已下单 | 全部已下单未入库 |
| 执行中 | 明细行状态混合 |
| 未开始 | 全部未下单 |

### 4.2 采购订单统计

| 卡片 | 说明 |
|------|------|
| 订单总数 | 所有未作废订单 |
| 已完成入库 | 全部到货 |
| 部分入库 | 部分到货 |
| 未入库 | 未到货 |
| 待审核 | auditflg='1' |
| 已退回 | auditflg='9' |
| 已作废 | useflg='9' |

### 4.3 逾期预警

**采购需求逾期**：计划日期 > 7 天且计划状态未完成（显示计划日期、当前日期、逾期天数）  
**采购订单逾期**：
- 审批滞留：待审核超过 3 天
- 交付逾期：已审核但超交付日期未入库

### 4.4 数据下钻

- 点击统计卡片 → 弹窗显示对应单据列表
- 点击 Top10 物料行 → 弹窗显示该物料在各需求单的明细
- 逾期表支持按状态筛选

## 5. 筛选优化

### 5.1 订单列表

| 筛选条件 | 说明 |
|----------|------|
| 审批状态 | 下拉（动态 AF 字典） |
| 执行状态 | 未入库 / 部分入库 / 已完成 |
| 作废单据 | 独立按钮切换，与正常单据隔离 |

### 5.2 需求列表

| 筛选条件 | 说明 |
|----------|------|
| 审批状态 | 下拉（动态 AF 字典） |
| 执行状态 | 未开始 / 已下单 / 执行中 / 已完成 |
| 逾期 | 快捷按钮 |

### 5.3 订单创建需求选择器

- 排除已完成的需求单（`exclude_completed`）
- 排除无可订余额的需求单（`hide_unavailable`：所有行 available_qty = 0）
- 排除已作废需求单（`useflg='9'`，全局过滤）

## 6. 物料编码保护

| 保护项 | 说明 |
|--------|------|
| 与分类编码冲突 | 创建/编辑物料时检查 `item_cd` 是否与 `tmm11_itemclass.class_cd` 冲突 |
| 外键约束 | ON UPDATE CASCADE：改物料编码自动同步 4 张引用表 |
| 引用表 | tpc02_pcplandt, tpc13_registerdt, tmm24_custitems, tip02_supplier_price |
| 作废流程 | 编辑减少订单数量 → 同步调减需求 auditqty，余额不会虚增 |
