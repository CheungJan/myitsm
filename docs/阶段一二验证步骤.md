## 阶段一：周期字段 UI 统一与配置复用

### 验证点 1：SupplierList 供应商品弹窗 - 周期字段 tooltip

1. 导航到 采购管理 → 供应商管理
2. 找一个有数据的供应商（如 "00000003 广州中崎"），点击 **详情**
3. 切换 tab → **供应商品**
4. 点击 **+ 新增供应商品**

7. 验证物料选择是 **树形多选下拉框**（el-tree-select），可按分类层级展开选择物料

### 验证点 2：SupplierList 供应商品弹窗 - 多选新增

### 验证点 3：SupplierList 供应商品弹窗 - 编辑

4. **预期**：提示 "修改成功"，列表中更新显示

### 验证点 4：ItemList 供应商 tab - 周期列展示

## 阶段二：价格基准校验

### 前置准备：确认测试数据

需要一个**有标准采购价的物料**，和一个**已关联该物料的供应商**。

```bash
# 查询有标准采购价的物料（TIP01 表，busityp='20'=采购价）
psql -U cheungjan -d myitsm -c "
  SELECT p.itemcd, i.item_nm, p.itemprice, p.busityp
  FROM tip01_price p
  JOIN tmm12_items i ON p.itemcd = i.item_cd
  WHERE p.busityp = '20' AND p.is_current = true
  LIMIT 10;
"
```
| 编码 | 含义     |
| ---- | -------- |
| 10   | 销售价   |
| 20   | 采购价   |
| 30   | 维护品价 |

记下返回的 `itemcd` 和 `itemprice`（标准价）。

如果没有数据，先给某个物料添加标准采购价：
```bash
# 在物料管理的"商品价格"tab 中添加一条 busityp='P' 的价格记录
# 或者直接 SQL：
psql -U cheungjan -d myitsm -c "
  INSERT INTO tip01_price (itemcd, busityp, itemprice, is_current, useflg)
  VALUES ('<物料编码>', '20', 100, true, '1')
  ON CONFLICT (itemcd, busityp) DO UPDATE SET itemprice = 100, is_current = true;
"
```

确保该物料已关联到你测试的供应商（在供应商详情 → 供应商品中已添加）。

### 验证点 6：正常价格直接保存（≥80% 标准价）

1. 打开供应商详情 → **价格报价** tab
2. 点击 **+ 新增报价**
3. 选择有标准采购价的物料
4. 填写单价为 **标准价的 85%**（例如标准价 100，填 85）
5. 点击保存
6. **预期**：直接保存成功，提示 "新增成功"，无弹窗警告

### 验证点 7：低价触发警告（<80% 标准价）

1. 再次点击 **+ 新增报价**
2. 选择同一个物料
3. 填写单价为 **标准价的 60%**（例如标准价 100，填 60）
4. 点击保存
5. **预期**：弹出确认对话框：
   - 标题：**"价格警告"**
   - 内容：`"报价 60 低于物料标准采购价 100.0 的 80%，是否确认保存？"`
   - 按钮：**"强制保存"** / **"取消"**

### 验证点 8：强制保存（确认警告后保存）

1. 在警告弹窗中点击 **"强制保存"**
2. **预期**：报价保存成功，提示 "新增成功"，列表中显示该报价

### 验证点 9：取消保存（不保存）

1. 再次新增报价，填入低价（如 50）
2. 在警告弹窗中点击 **"取消"**
3. **预期**：弹窗关闭，报价**未保存**，列表无新增

### 验证点 10：编辑报价不触发校验

1. 点击已有报价的 **编辑**
2. 修改为低价（如 50）
3. 点击保存
4. **预期**：直接保存，**无警告弹窗**（编辑不校验价格）

### 验证点 11：无标准价时直接保存

1. 找一个**没有标准采购价**的物料（即 TIP01 表中没有 busityp='P' 的记录）
2. 新增供应商报价，填写任意价格
3. **预期**：直接保存成功，无任何警告

```
验收清单：
[ ] 报价 ≥80% 标准价 → 直接保存，无警告
[ ] 报价 <80% 标准价 → 弹窗警告，显示标准价和百分比
[ ] 点击"强制保存" → 报价保存成功
[ ] 点击"取消" → 报价未保存
[ ] 编辑报价 → 不触发校验
[ ] 无标准价物料 → 直接保存
```
