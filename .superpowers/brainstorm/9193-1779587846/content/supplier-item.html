供应商商品关联维护 — 现状与方案

核心问题：从物料侧可以关联供应商，但从供应商侧看不到/管理不了它的商品

当前状态

维度已有缺失
物料 → 供应商 ItemList.vue 编辑物料 → "供应商" tab
CRUD API: /items//suppliers		 —
供应商 → 商品 — SupplierList.vue 详情里有空表格
缺少 GET /suppliers//items
缺少在此处新增/删除关联
供应商价格 tip02 模型存在 完全无 API/Service/前端
PB 版在供应商编辑窗口中有"报价"tab

数据模型关系

tmm19_suppliers (供应商) ← tmm24_custitems (关联) → tmm01_items (物料)
关联表字段：itemcd + custcd (联合PK) + dfltflg + delivercycle + servicecycle + guaranteeperiod

tip02_supplier_price (供应商报价)：itemcd + supp_cd + min_qty + itemprice + effective_date + expire_date

两种设计思路

A

在供应商详情中管理商品（推荐）

SupplierList.vue 的详情弹窗里，"供应商品"表格支持完整的增删改 + 价格维护

优点

  • 符合 PB 版操作习惯（供应商窗口 → 商品tab）
  • 采购专员在供应商页面一站式管理
  • 新增 GET/POST/DELETE /suppliers//items 即可
B

保持现状 + 独立价格管理页

供应商-商品关联仅从物料侧管理，另建供应商价格管理页面

缺点

  • 采购专员需在两个页面切换
  • 与 PB 操作习惯不一致
