供应商主数据 CRUD — 字段分级

21 个字段按使用频率分三级，列表只显示核心字段，表单展示全部

字段分级建议

级别 字段 显示位置 理由
L1 核心 supp_cd, supp_nm, custanm(简称), custbrcd(简码), class_cd, contactor, phoneno, useflg 列表 + 表单 日常采购选供应商、打电话、看分类
L2 扩展 address, zipcd, faxno, taxno, banknm, bankaccno, pcrep 仅表单 下单、开票、付款时才需要
L3 系统 scale(等级), suppinfo, agreements, custcd, custnm, opercd, gendate, upddate 表单底部 / 隐藏 Oracle 遗留字段，基本不用

Dialog 弹窗（推荐）

Element Plus Dialog，宽度 650px，扩展信息用 el-collapse 折叠

优点

  • 不离开列表页上下文

独立路由页面

/suppliers/new、/suppliers/:id/edit，Tab 分步表单

缺点

  • 需新增路由
  • 字段不多，Tab 分步意义不大
  • 与其他模块模式不一致
